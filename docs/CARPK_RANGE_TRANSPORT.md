# CARPK 圖片傳輸補充

2026-10-22。固定鏡像可連線，但單連線下載包含 train 的整個 2.08 GB 壓縮包過慢。伺服器已確認支援精確 HTTP Range，因此新增只讀 test 圖片的傳輸入口：解析固定 ZIP 的目錄，以最多八個並行連線取得 459 張所需圖片，不下載不需要的 train 圖片。

不修改正式評估來源或方法。每張解壓後仍須逐位元匹配已凍結的作者官方 SHA；標註來自官方包。由於不再取得整包，不能聲稱驗證鏡像整包 SHA，改記目錄 SHA、固定版本及全部官方逐圖 SHA。原慢速下載停止、部分檔案保留並可讀取已收到的範圍；先核對原下載程序身份，避免兩個程序寫同一檔。整次範圍傳輸最多 900 秒，網路錯誤每範圍最多重試一次，來源不符直接停止。

首次範圍讀取在解壓前遇到 ZIP64 的 `0xffffffff` 長度佔位，因圖片大小保護而停止，尚未接受任何圖片。核對原始目錄後確認真實長度保存在 ZIP64 extra 欄位；補上標準 ZIP64 長度／offset 解析並檢查後再執行。已收到的約 981 MB 壓縮前綴保留供讀取，官方逐圖 SHA 規則不放寬。
