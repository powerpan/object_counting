# CARPK 跨資料集結果

2026-10-22。使用凍結的 FSC-147 方法直接測試，沒有以 CARPK 選參或重新訓練。官方 test 共 **459 張、47,500 輛車**，每張平均 103.49、中位數 112、範圍 2–188。

| 指標（越低越好） | B0 | 最終系統 |
|---|---:|---:|
| MAE（輛／圖） | 8.51416 | 8.69717 |
| RMSE（輛／圖） | 14.27309 | 14.71124 |
| GAME(1) | 10.85655 | 10.78884 |
| GAME(2) | 15.48308 | 15.29890 |
| 平均純推論秒／圖 | 0.20967 | 0.44248 |

11 張（2.40%）觸發 M3，其餘使用 T2。MAE／RMSE 點估計略差，空間分布誤差略低。圖片配對差值（最終減 B0）的 95% 區間分別為 MAE [−0.04469, +0.40526]、RMSE [−0.17062, +1.01477]；兩者跨零，**沒有跨資料集改善的證據**。不能由 GAME 下降宣稱計數改善。

每張取官方標註檔原順序的前三個框作示例。五張只有兩輛車，按推論前提交的修訂重複第二框作第三個提示，真值仍為 2，沒有排除圖片。這是有示例的計數設定；與使用不同提示或零提示的文獻不能直接排名。CARPK 只有車輛一類，類別 bootstrap 退化為單一數值，不能作跨類別推論；圖片抽樣亦未充分處理同一停車場相近畫面的相關性。

原始官方壓縮包經授權取得；伺服器從固定版本鏡像提取圖像，每張均通過官方原檔 SHA-256，比較時只用官方標註。公開倉庫不含下載密碼、授權人資料或圖像。伺服器核算重建全部密度、GAME 與定位，本機再核對官方真值／示例、尺寸、全部計數與配對區間，均通過。每個方法的完整 test 只執行一次。
