# 類別無關物件計數：最終評估與交付報告

2026-10-23（香港；正式測試於 10 月 22 日 UTC 完成）｜方法已凍結；以下 test 與 CARPK 均為一次性評估。

我們完成了一套以三個視覺示例指定目標類別的計數系統，可輸入單張 RGB 圖片，輸出估計數量、密度疊圖及檢測框。最終方法在 FSC-147 test 上降低平均與長尾計數誤差，但配對區間仍跨零，未通過完整事前成功標準；CARPK 的計數點估計略差。這份報告保留改善與失敗，沒有以測試結果回頭選參。

## 1. 任務、方法及資料如何分開

目標是對未見類別進行有示例的物件計數，並觀察密集、尺寸變化與背景干擾下的表現。「類別無關」指不必為每種新物件重新訓練；本系統仍需要三個框作提示，不能理解為完全無提示的任意物件辨識。

B0 為固定官方 GeCo2 與 SAM2 權重。M1 把每個檢測框轉為質量為一的密度分布，圖像密度總和等於計數；它是由檢測生成的密度圖，不是獨立學習的密度回歸器。

最終路由已於 test 前凍結：若 B0 計數 ≥200，或三個提示的中位邊長在模型座標 ≤32 像素，使用 M3-v2 的 3×3 切片（10% halo），各片沿用完整圖的 SAM 分支；其餘使用 T2，平均原圖與水平翻轉的計數及回投密度。沒有 M2、強制遮罩、校正或後續微調。B0 與最終方法以同一圖、同一提示配對比較。

| 資料用途 | 圖片／類別 | 目標數與每圖分布 | 使用限制 |
|---|---|---|---|
| FSC-147 train | 3,659／89 | 用於原 S／v2 訓練及內部 holdout | 未將 holdout 成績當官方 val |
| FSC-147 val | 1,286／29 | 82,042；中位 27，範圍 7–2,092 | 多輪開發與類別兩折選擇，已有開發適應風險 |
| FSC-147 test | 1,190／29 | 78,836；中位 36.5，範圍 8–3,701 | 凍結後只跑一次，不選參 |
| CARPK test | 459／1 | 47,500；中位 112，範圍 2–188 | 固定設定直接跨資料集評估 |

CPU 檢查、來源雜湊及 32 張 val 等價 gate 先通過，再開始正式測試。完整密度、計數、GAME 與定位由伺服器獨立核算；本機再核對官方真值、提示、實際圖像尺寸、計數及配對區間。統計重算沿用事前固定算法，不能稱為另一套獨立統計方法。

誤差有長尾：`1123.jpg` 真值 3,701，B0 為 2,767、最終為 3,144，是大幅改善；`7171.jpg` 真值只有 13，B0 卻為 857、最終為 940，為嚴重過計且再退步。這兩者一併呈現，不只展示成功案例。定性選圖按事前隨機六張、最差六張及改善／退步各三張；重複圖片合併後共 16 張。


MAE 是每圖絕對數量誤差的平均；RMSE 對少數大誤差較敏感，兩者單位均為個／圖。不能把 MAE 除以平均目標數當成逐圖平均相對誤差。GAME 是分區計數誤差，能反映位置分布，但不等同分割品質。定位 precision／recall 需一對一匹配，與先前只看預測總數的「檢測率」不同。

## 4. 未採用方法與原因

- M2：自行擴充示例有把多個物件包入一框的風險；v2 增加品質過濾和回退後，折內納入仍失敗。這是固定候選的負結果，沒有再調門檻。
- M4-S：完整 val 明顯退步；原 fit 中 ≥500 的 15 張，中位預測／真值僅 0.35433，顯示連訓練密集圖也擬合不足。觀測最大計數約 389，不是已證明的架構硬上限。
- M4-v2：以 M1 零殘差起點改正輸出，32 圖初始計數最大差 3.80×10⁻⁷；第 10 輪內部 holdout RMSE 17.08497 高於同集 B0 的 16.52019，因此自動停止。該 holdout 為 396 張／10 類，不能拿這個數字與完整 val 相比。
- S／v2 失敗可能與訓練類別缺少可學的基線錯誤、密集樣本不足、損失設計有關；尚無因果實驗證明共同原因。S 的訓練集擬合不足也限制了單純「只是不泛化」的解釋。
- L 提早取消，沒有正式評估；初期指標曾被讀取，不能宣稱完全盲化。保存 SHA 只能證明檔案完整性，不能證明未使用。
- M4-v3 的五參數 Poisson 區域校正與單一全局倍率都被折內納入拒絕；以驗證集擬合不等於能穩定跨類別泛化。TTA、遮罩或校正的額外收益不能由組合表格直接拆解。

## 5. CARPK

2026-10-22。使用凍結的 FSC-147 方法直接測試，沒有以 CARPK 選參或重新訓練。官方 test 共 **459 張、47,500 輛車**，每張平均 103.49、中位數 112、範圍 2–188。

|---|---:|---:|

| RMSE（輛／圖） | 14.27309 | 14.71124 |
| GAME(1) | 10.85655 | 10.78884 |
| GAME(2) | 15.48308 | 15.29890 |

11 張（2.40%）觸發 M3，其餘使用 T2。MAE／RMSE 點估計略差，空間分布誤差略低。圖片配對差值（最終減 B0）的 95% 區間分別為 MAE [−0.04469, +0.40526]、RMSE [−0.17062, +1.01477]；兩者跨零，**沒有跨資料集改善的證據**。不能由 GAME 下降宣稱計數改善。

每張取官方標註檔原順序的前三個框作示例。五張只有兩輛車，按推論前提交的修訂重複第二框作第三個提示，真值仍為 2，沒有排除圖片。這是有示例的計數設定；與使用不同提示或零提示的文獻不能直接排名。CARPK 只有車輛一類，類別 bootstrap 退化為單一數值，不能作跨類別推論；圖片抽樣亦未充分處理同一停車場相近畫面的相關性。

原始官方壓縮包經授權取得；伺服器從固定版本鏡像提取圖像，每張均通過官方原檔 SHA-256，比較時只用官方標註。公開倉庫不含下載密碼、授權人資料或圖像。伺服器核算重建全部密度、GAME 與定位，本機再核對官方真值／示例、尺寸、全部計數與配對區間，均通過。每個方法的完整 test 只執行一次。

## 8. 審計結論與限制

交付已包含可執行的有示例計數系統、密度圖與定位、完整量化／定性材料，以及未採用路線的證據。FSC-147 test 的點估計有改善，但區間跨零；CARPK 未改善。不能寫成已證明所有未見類別、密度、尺寸或遮擋情境都穩健，也不能以開發 val 的較佳數字替代最終 test。
