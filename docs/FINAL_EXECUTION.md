# 最終評估執行口徑

方法與成功條件沿用 `final_v1.json`。本次只把已凍結的 M3 3×3／T2 路由接成可直接使用的推論入口，不新增模型或調整參數。

先完成異地備份及逐物件 SHA 核對。新實例以原來的 32 張 val 圖檢查 native／adapter 原始輸出及已保存 B0 框的逐位元一致性，再執行一次 FSC-147 test。每張圖分別計時 B0 與完整最終系統；最終系統自己的原圖分支必須等於同張 B0。測試真值只在推論返回後用於評分。

每張保存計數、框、原圖網格密度、耗時、顯存與方法路由。T2 的框與定位分數來自原圖視圖，計數及密度則取兩視圖平均；框數未必等於平均計數。CARPK 亦採相同設定，示例為官方標註檔原順序的前三框；點位置用全部車輛框中心，不把這項跨資料集結果用於調參。

核算程式不載入模型，從保存的框重新建圖，另以既有獨立逆投影函式重建 T2；核對檔案雜湊、密度質量、GAME、最大匹配定位、分組與配對區間。統計重算沿用同一已登記公式，不宣稱是不同統計方法的交叉驗證。

新帳本只記本次階段，舊帳本保留為帶 SHA 的歷史引用，不重複扣算。前置最多 1,800 秒，test 與 CARPK 合計最多 7,200 秒，demo 最多 3,600 秒；遠端 CPU 核算也保守計入階段牆鐘。來源不符、非有限值、顯存 allocated 超過 40,000 MiB、核算失敗或超時即停止，不自動重跑 test。原人工盲標及 kappa 依負責人修訂省略，報告保留此限制。

本機 13 項檢查涵蓋計數／分組／配對區間、時間帳本、demo 座標與 CARPK 凍結輸入；遠端 gate 與正式結果尚待執行。所有新入口先提交推送，執行時逐檔核對來源憑據。資料優先從公開來源直接下載到伺服器，FSC-147 每張須匹配原官方壓縮包 SHA；CARPK 按 [輸入補充](CARPK_INPUT_AMENDMENT.md) 核對官方原圖 bytes，五張雙車圖片採固定重複提示。demo 的啟動、模型載入與互動全部納入同一預算及失敗清理範圍。
