原始三個示例框在 B0 輸入中的面積平方根中位數 ≤32 像素，或 B0 計數 ≥200，便走 M3-v2 3×3。裁片沿用全圖的自動 SAM 分支，halo 為全圖尺寸的 10%，所有裁片共用最大 objectness 的 0.11 倍門檻，NMS IoU 0.5。其他圖片走 T2：原圖與水平翻轉，將框逆投影回原圖後各自生成 M1，再平均密度與計數。不含 M2、強制遮罩或校正。

B0 是官方 GeCo2 原圖推論。B0 與最終系統在同一評估工作內逐圖配對；不取整預測。T2 的定位及顯示框沿用原圖視圖，平均密度的總量可為半整數，因此框數與平均計數不一定相等，報告和 demo 會明示。M1 是由檢測框構造的守恆高斯密度，不稱為學習式密度回歸。

## 評估定義

相對示例尺寸 `r = sqrt(mean(前三框面積)/(圖像寬×高))`。全部 1,286 張 val 的三分位數以 NumPy linear quantile 計算，界線為 **0.08481851881440144**、**0.15272090794772686**：小組 ≤下界、中組 >下界且 ≤上界、大組 >上界。使用實際 384 版圖像尺寸，不誤用標註中未縮放的原照片 H/W。test 不重新估界線。

密度分組為 <50、50–299、≥300。輸出整體、密度／尺寸分組和逐類別 MAE／RMSE，並交代圖片數、真值目標數與分布。GAME(1)/(2) 使用既有邊界規則；定位以框中心與真值點做最大基數一對一匹配，半徑為示例寬高平均值的 0.5 倍，precision／recall／F1 以彙總 TP/FP/FN 計算。圖片及類別各做 2,000 次配對 bootstrap，種子 42，差值為最終系統減 B0。

test 必須同時滿足 RMSE ≤0.98×B0、圖片 RMSE 差的 95% 區間上端 <0、≥300 組 MAE ≤0.95×B0、整體 MAE ≤1.02×B0，才報成功。其餘依證據報點估計改善但不確定或未改善。不以單一好看的指標取代完整判定。

定性圖選擇已寫入設定：種子 20261022 的六張隨機 test、最終絕對誤差最大的六張、相對 B0 改善與退步最多各三張；平手按圖名排序。重複入選保留理由但只繪製一份。機制圖只取 val 的 865.jpg、3665.jpg；demo 只用預先指定 val 圖，不額外重跑 test。
