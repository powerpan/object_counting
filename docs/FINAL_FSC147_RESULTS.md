# FSC-147 最終測試結果

2026-10-22。方法於測試前凍結，單次 test 已完成伺服器獨立核算，回收後再由本機核對官方真值、示例、實際尺寸、計數、分組與配對區間。**點估計改善，但未通過完整成功標準。** 沒有根據結果修改設定或重跑。

我們的系統仍是凍結的 M3 3×3／T2 路由，不加入 M2、強制遮罩或校正。B0 與最終系統使用同一批官方 test：**1,190 張、29 類、78,836 個目標**，每張平均 66.25、中位數 36.5，範圍 8–3,701。前三個官方示例框指定要數的物件；真值為點標註個數。MAE／RMSE 單位是「個／圖」，越低越好。

密集組只有 23 張，MAE 下降 28.02%；少量組及中尺寸組卻略差，不能說各種密度與尺寸均改善。尺寸為三個示例框平均面積相對圖像面積的平方根；小／中／大的兩個界線 0.08481852／0.15272091 在 val 上事先固定，沒有使用 test 重分組。

差值一律為最終系統減 B0。圖片配對 MAE 區間為 [−1.06983, +0.22185]；類別配對 MAE／RMSE 區間為 [−1.27684, +0.28181]／[−17.63885, +3.69638]，也跨零。均為事前固定 2,000 次、seed 42。結論是尚未排除零改善，不能把數值下降直接寫成已證實成功。

誤差有長尾：`1123.jpg` 真值 3,701，B0 為 2,767、最終為 3,144，是大幅改善；`7171.jpg` 真值只有 13，B0 卻為 857、最終為 940，為嚴重過計且再退步。這兩者一併呈現，不只展示成功案例。定性選圖按事前隨機六張、最差六張及改善／退步各三張；重複圖片合併後共 16 張。

本次凍結來源為 `083b6ee` 的 142 檔，保留原官方權重；克隆前置 13 項 CPU 檢查及 32 圖等價 gate 通過。完整 test 推論、保存和統計約 699 秒，獨立核算另計。B0／最終平均純推論延遲約 0.142／0.352 秒／圖，allocated 峰值約 5,517／5,000 MiB；GPU 為 vGPU-48GB。計時含各自的輸入準備與完整方法，並非網頁端到端延遲，也不等於雲端帳單。
