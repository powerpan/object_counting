# 備份與展示補充

伺服器內已封存 25,741 個檔案，包含六個訓練檢查點及 23,756 份可對照既有 SHA 的密度檔。去重後歸檔為 6,370,596,924 bytes。首次 Mac 回傳速度不足，已停止傳輸並保留片段；沒有把未完成的回傳寫成已備份。

負責人明確同意建立 AutoDL 同區文件儲存，只使用 20 GB 免費額度，不擴容或購買付費容量。歸檔將複製到獨立於實例磁碟的掛載點，核對整包 SHA、清單 SHA 及全部 7,730 個去重物件。核對完成後才允許正式評估。平台畫面顯示：文件儲存若連續三個月未登入或欠費達其規定門檻，平台保留刪除權；實例本地磁碟則有連續關機十五天釋放規則。兩者都不是永久保存承諾。

32 圖 gate 額外對照既有 M3 3×3／T2 的框、計數與密度格量，確認新路由只是既定方法的組接。此檢查在 test 前完成，不用 test 來修正方法。

Gradio 展示使用固定版本 5.49.1，服務只監聽 loopback，由私人 SSH 隧道連入。介面上傳 RGB 圖片，依序點選三個框的兩個角點；按計數後一次取得 B0 與最終系統，切換顯示不再次推論。預設展示圖只來自已登記的 val 一般圖與密集圖，記錄輸入內容 SHA、人工框座標、耗時及真實輸出；不附帶真值給推論函式。錄影和含原圖的展示成果留在私人交付資料夾，不放公開 Git。

含展示座標與空密度顯示檢查，目前本機合成測試共 12 項通過。實際 GPU 測試與操作錄影尚待執行。完成核對與成果回收後，依負責人最新指示在 AutoDL 關機，保留實例與磁碟。
