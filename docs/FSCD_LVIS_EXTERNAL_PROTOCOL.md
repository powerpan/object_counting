# FSCD-LVIS 補充對照

2026-11-09，首次推論前登記。我們將已凍結的 FSC 專用 GeCo2 基準和 M3 3×3／T2 系統原樣放到 FSCD-LVIS，檢查跨資料集表現。這項工作承接學校 GPU 遷移；不在新資料上訓練、校正或選參。CARPK 的既有結果保留，本次對照是補充，不能承諾換資料後一定改善。

## 資料與適用範圍

FSCD-LVIS 同樣以少量示例框指定計數目標，但含複雜背景和其他類別；選用理由是任務形式接近，而非已知本系統在它上面得分較好。[原作者說明](https://github.com/VinAIResearch/Counting-DETR)

原作者 README 的兩個下載資料夾在本機與學校端均返回 404。TMR 作者在公開問題回覆中提供臨時副本，明確說明並非原作者上傳。本次固定該副本的 Hugging Face revision、大小及 LFS SHA-256（見設定檔），先驗證完整 6,257,600,910-byte 壓縮包，再使用其中標註和圖片。這能保證使用同一副本，不能冒稱已與目前無法取得的原始壓縮包逐位元比對。[鏡像提供者說明](https://github.com/Chipmunk-g4/Template-Matching-and-Regression/issues/7#issuecomment-4089176424)

使用 `unseen_count_train/test.json` 與 `unseen_instances_train/test.json`，檔名及 ID 對齊方式對照 TMR 固定版 `f378250836b27c8577cd51c3a4a85fbb61a4e222` 的資料讀取程式。先核對壓縮包是否完整提供這四檔、每圖尺寸、示例框及點標註、同圖目標類別和 instance 數；若不相符先停在資料核驗，不換成另一個分割湊數。實際樣本數以核對後清單為準，必須在首次 GPU 推論前固定。

模型仍用已核驗的 `GECO2FSCD.pth`，不用作者的 multi-dataset demo 權重。原始發布將此權重列在 FSCD147 重現段落；本次不把論文使用另一資料集訓練的數字當成自己的基準。FSCD-LVIS 的「unseen」描述其自身訓練／測試分類，不能直接推論所有類別也未出現在 FSC-147 或基礎模型預訓練資料。[GeCo2 權重說明](https://github.com/jerpelhan/GECO2#reproducing-results-on-fscd147)

先用已保存的 FSC train／val／test 檔案 SHA 清單查完全相同的圖片；若查出重複，保留完整官方分割和去重補充表，不能悄悄刪除。此檢查不能排除重新編碼、裁切或預訓練污染。資料只供學術用途，原圖、原始標註、含標註的逐圖清單不放公開倉庫；公開方案、程式、檔案雜湊與彙總結果，遵守原作者不再分發資料的要求。

## 固定流程

1. 學校 CPU 作業下載並核對完整壓縮包，只先展開標註；原始程式、權重及三圖部署核驗須保持通過。Mac 只傳小型程式，不傳大資料。
2. 完成資料適配與獨立核算程式，測試 ID 對齊、`xywh → xyxy`、目標數量及異常拒絕。清單、入口及相應來源憑據先提交推送，才跑 GPU。
3. 按數值 image ID 遞增取 unseen train 前 20 圖做小批核驗。固定前三個官方示例，保留浮點座標，RGB 原圖交給原系統預處理；不用 TMR 自己依真值框觸發的放大策略。小批只驗證技術正確性、資源及時間，不按其精度決定是否做完整對照。
4. 技術核驗通過且按實測估時足以在上限內完成，才對完整 unseen test 做一次 B0／凍結系統成對推論。依圖片與示例作路由，目標點／框只在推論後用於統計。不改 M3 門檻、T2 尺度、NMS、示例順序或權重。
5. 獨立從逐圖輸出和原始標註重算指標，核對完整性、密度總量、來源雜湊及有效圖片數。結果回收後更新繁體中文文件並推送；結果不好也照樣保存。

## 報告與判斷

主指標是每圖 MAE、RMSE，並列圖片數、目標總數及每圖數量最小／中位／平均／最大值。另報 GAME(1)、GAME(2)、路由比例、時間和顯存，方便理解空間分布與成本。每圖配對 bootstrap 10,000 次、seed 20261109，報告「凍結系統減 B0」差值的 95% 區間。以圖像為抽樣單位；若同一原圖出現多筆目標，按原圖分組抽樣，不能當獨立圖像。

只有 MAE、RMSE 皆較低才稱兩個計數點估計改善；兩者區間上界皆小於零，才稱本次對照支持計數改善。空間指標獨立說明，不能用它掩蓋計數退步。這是新增資料集的補充判準，並未修改已完成 FSC test／CARPK 的成功標準。

## 資源與停止條件

使用現有學校環境；下載 CPU 最多 40 分鐘，4 核。GPU 單卡 L20、4 核、batch 1：小批最多 15 分鐘，完整最多 2 小時；主機記憶體由學校按比例分配，allocated 上限 24 GiB。資料尚未備好時不占 GPU。下載採固定四路分段，每段最多三次網路錯誤重試，最終必須通過完整 SHA；這不是實驗重跑。

OOM、非有限值、錯配標註、資產或來源差異、密度總量不符、預算不足均保存診斷並停止相依階段。實作問題須有明確原因、有限修復，保留原證據，先提交修訂再執行。禁止因效果不佳改資料、調參、追加候選，亦不重做舊正式 test 或啟動微調。

目前只完成學校部署與資料來源核對；本文件不是新資料集的實測結果。
