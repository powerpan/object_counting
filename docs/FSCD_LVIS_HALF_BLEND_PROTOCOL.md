# FSCD-LVIS 等權混合：事後探索規則

2026-11-09。我們已看過完整 FSCD-LVIS test：原系統 MAE 比 B0 低，但 RMSE 高約 0.05%。負責人要求嘗試低成本改法，使這個資料集的 MAE、RMSE 都不高於 B0。因此另開一個探索分支，原凍結方法、原報告及其他資料集結果均保留。

這是**看過測試結果後提出的方案**。先提交本規則與程式，只能證明下述單次核算前固定了做法，不能讓同一批 test 恢復成未見測試集，也不能追認原成功標準已通過。

## 只試一個方案

對每張圖，取 B0 與原 M3 3×3／T2 系統輸出的等權平均：

`N_half = (N_B0 + N_original) / 2`

`D_half = (D_B0 + D_original) / 2`

比例固定為 0.5／0.5，沒有候選網格、擬合係數、分組比例、誤差截斷或按真值切換方法。保留小數計數；不四捨五入，不把密度峰值當成新的整數檢測框。推論函式只接收兩組預測，沒有真值輸入。

理由是平均能減少兩個方法不同方向的大錯誤。絕對誤差的凸性保證這批資料的混合 MAE 不大於兩個原 MAE 的平均；RMSE 是否改善仍須實測。這不是對新資料的保證，也不等於解決了原模型的外部分布問題。

## 核算範圍與判讀

固定原完整 2,242 張圖、84,298 個目標、相同官方提示及真值，不刪除任何失敗樣本。使用原已核算的計數與密度檔，SHA 固定於 `configs/fscd_lvis_half_blend_v1.json`。原六份來源憑據仍須通過；新入口另存憑據，不覆寫舊來源。

表格同時列 B0、原系統與混合方案。主要目標為混合方案 **MAE ≤ B0 且 RMSE ≤ B0**，以未捨入值判定；GAME(1)/(2) 作附加空間指標。圖片 SHA 分組配對 bootstrap 維持 10,000 次、seed 20261109，另報兩個差值區間。達到點估計目標與區間支持改善分開判讀；區間未校正此次事後提出方法造成的選擇影響，不當作獨立確認。

CPU 入口逐圖驗證來源密度檔、非負與有限值、原圖尺寸及質量。混合密度質量須與混合計數相差不超過 `1e-6`。GAME 使用兩種格統計實作交叉核算；計數另用 `math.fsum` 重算。新逐圖輸出含來源及混合陣列 SHA，留在私人工作區；公開彙總、核算及回收記錄。密度可由兩份來源按公式重建，不重存整批大陣列。

## 執行與邊界

程式、設定、測試和本文件先提交推送，再在學校既有環境提交一個 CPU 作業：4 核、最多 600 秒、CUDA 隱藏、0 GPU 小時。無需重新推論、下載資料或訓練。單元測試涵蓋小數計數、空間質量、相同輸出、錯誤輸入與指標核算。來源不符、非有限值、核算失敗或超時即保留診斷停止，不自動重跑或調比例。

原 `FinalEngine` 不變；新增 `planb.half_blend.half_blend` 作為可選後處理。其輸入可直接接 `FinalEngine.run_pair` 的 B0、原系統計數和密度。此次測量的是已保存輸出的 CPU 重放，**不是新測得的即時推論速度**。成功時只聲稱這批已觀察資料上的探索結果；若要聲稱未見資料泛化，需要另留未用於開發的確認資料。

不啟動其他資料集、微調或第二個混合比例；無論結果好壞均保存並報告。
