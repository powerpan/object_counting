# FSCD-LVIS 等權混合探索結果

2026-11-09。我們把 B0 與原 M3 3×3／T2 系統的計數和密度各取一半，在相同 2,242 張圖上取得 **MAE 48.58463、RMSE 139.75140**。兩項點估計都低於 B0，達到本次「兩指標不退步」的目標；代價是放棄原系統一部分 MAE 優勢。

方案是在看過原 test 成績後提出，只試固定 50/50 一組，沒有搜尋比例、訓練或刪圖。因此這是**事後探索結果**，不能作為新的獨立測試，也不改寫原系統未通過雙指標判準的記錄。

## 相同圖片、相同真值的比較

使用原 FSCD-LVIS unseen test 全部 **2,242 張互異來源圖、84,298 個目標**。每圖平均 37.60、中位數 29、範圍 21–709。真值、官方三個示例框及原預測均未變更。MAE／RMSE 的單位是個／圖；下表各指標越低越好。

| 指標 | B0 | 原 M3／T2 系統 | 50/50 混合 | 混合相對 B0 |
|---|---:|---:|---:|---:|
| MAE | 53.77609 | 44.23037 | **48.58463** | −9.65% |
| RMSE | 143.54587 | 143.61556 | **139.75140** | −2.64% |
| GAME(1)，2×2 區域 | 56.73470 | 47.49829 | **51.53076** | −9.17% |
| GAME(2)，4×4 區域 | 60.33404 | 51.18351 | **55.03242** | −8.79% |

混合相對原系統的 MAE 高 9.84%，RMSE 低 2.69%。它提供平均誤差與大誤差之間的另一個取捨，並非每張圖都更準。GAME 是混合密度重新計算的結果，沒有直接平均兩個方法的 GAME。平均真值只有 37.60，而混合 MAE 仍有 48.58，因此這組結果仍不能稱為可靠的外部泛化。

依固定的圖像 SHA 分組配對 bootstrap（10,000 次，seed 20261109），差值為混合減 B0：

| 指標 | 差值 | 95% 區間 |
|---|---:|---|
| MAE | −5.19146 | [−6.55411, −3.85515] |
| RMSE | −3.79447 | [−15.96360, +10.23562] |

MAE 的條件區間低於零；RMSE 區間仍跨零，不能宣稱已證實兩項都穩定改善。這些區間沒有校正「看過 test 後才提出混合」的選擇影響。若要確認未見資料的效果，需要另用未參與開發的資料。

## 做法與可用介面

`N_half = 0.5 × N_B0 + 0.5 × N_original`

`D_half = 0.5 × D_B0 + 0.5 × D_original`

權重對所有圖片相同，不讀取真值、不依圖像誤差選方法，也不四捨五入。原 `FinalEngine` 保留，新增可選後處理函式：

```python
from planb.half_blend import half_blend

b0, original, d0, d1, detail = engine.run_pair(image, exemplars)
count, density = half_blend(
    b0['prediction'], original['prediction'], d0, d1
)
```

輸出的密度總量等於計數。混合後沒有對應的合併整數檢測框集合；若展示來源框，應標明其來源，不能宣稱框數等於混合計數。此次只核算已保存輸出，尚未另外測量混合模式的即時端到端延遲。
