# M2／M3 第一輪實驗規則

登記日期：2026-10-18。設定版本：`configs/m2_m3_v1.json`。本文件先於 M2／M3 的實際結果建立；後續修正會另外記錄，不回寫成事前決定。

我們已完成 GeCo2／SAM2 的 B0：完整 val MAE 9.38958、RMSE 33.26304，密集組 39 張的 MAE 113.43590。這輪保持模型權重凍結，只檢查補充示例和切片推論是否有幫助；不訓練、不讀 test 圖像，也不修改 B0 結果。

## M2：補充未覆蓋尺度的示例

第一輪沿用 B0 的三個示例和預處理。從最終檢測框中找出候選，框的 objectness 至少為第一輪最高值的 0.5；候選與原始示例的三層 RoI 特徵，平均餘弦相似度至少 0.75。objectness 是排序依據，不解釋為已校準機率。上游在候選超過 800 個時會略過 SAM 遮罩修正，因此不把輸出的 `scores` 一律當作 SAM IoU 使用。

用框面積平方根定義尺度。候選與每個原始示例的尺度比例，至少相差 1.5 倍，且縮放後兩邊皆至少 2 像素。按相似度與相對 objectness 的乘積排序，每個以 1.5 倍分隔的尺度區間最多選一個，總計最多三個。沒有合格候選就保留 B0。

第二輪保留原本三個示例，再加入候選；保持第一輪的圖像縮放，重用同一組主幹特徵，避免把重新縮放混入 M2 效果。最後採第二輪檢測，不把兩輪直接加總。記錄候選框、相似度、分數、尺度與第二輪前後數量。標註點僅在推論結束後評估候選是否覆蓋已標註物件；此檢查只是目標漂移的代理證據，不能代替人工辨識。

`m2-repeat` 對照採相同觸發與新增示例數量，但新增的是循環複製的原始示例；同樣做第二輪、重用主幹。兩者示例 token 數相同，用來區分新尺度資訊與重複提示／額外計算的影響，並另報實測時間，不能宣稱 FLOPs 完全相等。

## M3：全圖示例特徵引導的重疊切片

第一輪後，若原始三個示例在 B0 輸入中的面積平方根中位數不大於 32 像素，或第一輪預測至少 200 個物件，就觸發切片。只讀輸入示例和預測，不讀真實數量。其他圖片直接保留第一輪結果。

將原圖分成 2×2 個核心區，每個區向相鄰方向延伸全圖寬／高的 10%，形成重疊裁片。每片依長邊縮放至最多 1024，並保留上游平均示例尺寸不超過 80 的限制，再補邊至 1024。所有裁片循序推論，一次僅保留當前裁片的主幹和遮罩，先控制顯存再看吞吐。

示例外觀特徵從全圖的三層主幹特徵擷取，直接傳給各裁片的 query 模組；形狀特徵依裁片縮放比例重新編碼。這樣示例即使不在裁片內，也不需要偽造框或拼貼圖片。這個特徵重用方式是本輪方法假設，是否有效需由結果判定。

裁片檢測先還原原圖座標，只保留中心落在該片核心區內的框；核心區採不重疊的半開區間，確保邊界只有一個歸屬。合併後用 IoU 0.5 的 NMS 去重，分數在片內以最高 objectness 正規化。觸發圖片採切片結果，不再與全圖框直接相加。

`m3-repeat` 對照採相同觸發，額外跑四次原全圖推論，保留最後一次結果；檢查輸出是否與 B0 相同並量測實際成本。它控制推論次數，不代表與不同裁片的遮罩候選數／FLOPs 完全一致。

## 預先固定的比較

| 組別 | 做法 |
|---|---|
| B0／M1 | 已完成的原始 GeCo2 計數及守恆密度圖 |
| M2 | 原始三示例＋新尺度候選，最多兩輪 |
| M2-repeat | 複製同數原始示例的第二輪對照 |
| M3 | 第一輪後依固定條件切片，使用原始三示例特徵 |
| M3-repeat | 同觸發條件，多做四次原全圖的對照 |
| M2＋M3 | 先做 M2，M3 依原始示例尺度和 M2 預測決定觸發，使用增補後示例特徵 |

不做閾值網格搜尋，也不根據 smoke 的 MAE 修改這組參數。Smoke 選取少量低／中／高密度及極端數量圖片，只判斷程式、座標、有限值、輸出與顯存是否正常；選取規則和名單留存。所有組別最後都用相同的完整 1,286 張 val。這是開發用驗證，不能稱為獨立確認或最終測試。

前置條件：新特徵介面在 smoke 圖像上必須重現 B0 的原始輸出與最終計數；切片座標還原、核心區歸屬、尺度候選過濾及密度守恆通過測試。每輪都核對第一輪與既有 B0 的計數，防止實驗入口悄悄改動基準。權重、輸入和程式雜湊寫入執行記錄。

報告整體及少於 50／50–299／至少 300 個物件組的 MAE、RMSE、GAME，附真實數量分布、觸發比例、推論次數、耗時、顯存、改善／退步案例。以相同圖片配對 bootstrap 2,000 次估計與 B0 的差值區間，另以官方類別為單位重抽樣；區間描述本次 val 的變動，不能消除選參偏差。

本輪只把「整體 MAE 不高於 B0 的 102%、RMSE 下降、密集組 MAE 下降」列為進入後續確認的候選門檻，並同時檢查對照組與區間。即使某組通過，也不等於達成 Plan B 的最終 test 成功條件。未達門檻照樣記錄和推送負結果。

## 資源與停止規則

沿用現有 48GB 實例，不租新資源。本輪用 FP32、單圖／單裁片循序執行；一旦 OOM、非有限輸出、資料或 B0 計數不一致，即保存診斷並停止相依流程。PyTorch allocated 超過 40,000 MiB 時停止後續圖片，不無限重啟。每個完整組別最多 90 分鐘。這輪不啟動 M4 訓練。

每完成可核對進展或結果，更新繁體中文進度與去識別化證據後推送。結果包含每張圖的數字與設定，不發布資料集原圖、模型權重、私人日誌、連線資訊或個人身分。
