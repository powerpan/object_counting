# M4-v2：M1 殘差密度分支的事前規則

2026-10-18。以本文件首次公開提交為登記點；先提交推送，再執行 R2-1b 或任何 M4-v2 GPU 工作。設定為 `configs/m4_v2.json`、分割為 `configs/m4_v2_splits.json`。這是 S 負結果之後提出的設計，val 已參與研究方向制定，因此後續 val 仍是開發證據。診斷結果不得更改以下設定，之後任何修訂另立紀錄。

## 四組設計變更

1. 在凍結 GeCo2 的 256 通道 adapted、1 通道原始 centerness 之外，加上 M1 密度：**258 通道**。沿用 S 的 256→256→256→128→64 卷積寬度、GroupNorm 32、GELU 和最後 1×1。最後權重與偏差均為零，移除 Softplus，以有正負的殘差修正 M1。
2. 計數損失改為 `0.1 × |ΣD_raw − N| / sqrt(max(N,1))`；另加負密度懲罰。像素平均的原密度損失保留，並未單獨消除像素平均的影響。
3. 擬合集 ≥300 圖每輪出現四次，其餘一次。
4. 擴充類別互斥的 train-holdout，以報告用非負密度的 RMSE 選輪，並加入固定第 10 輪停止檢查。

這四組變更包含輸入、輸出／初始化、損失、取樣與選輪等相依實作，並非可隔離因果的四項消融。其餘設定沿用已固定的 S：GeCo2 全凍結、FP32、TF32 關閉、AdamW 1e-4、weight decay 1e-4、一輪 warm-up 後 cosine 至 1e-6、梯度裁切 1.0、30 輪、batch 8、seed 42；水平翻轉及尺度抖動、點標註高斯與有效區域規則沿用原實作。

## 密度定義與損失

M1 由同一次凍結 GeCo2／SAM2 前向的最終框生成，不用真值決定框或渲染輸入。按原 M1 函式在 512 網格的有效區域渲染：框座標由 1024 畫布除以二；σ 分軸為框邊長／6、下限 0.5 網格像素，截斷 3σ，每框重新歸一為一。補邊為零。

為保留 S 的數值尺度，最後卷積輸出記作 Q（乘 100 的殘差），`r=Q/100`；`D_raw=(M1+r)×有效遮罩`。推論、選輪和報告用 `D=max(D_raw,0)`。新增輸入通道使用未乘 100 的 M1。零初始化使第 0 輪計數回到檢測數；512 網格渲染與原圖 M1 的空間離散化不同，不能聲稱兩者逐像素相同。驗證另報零殘差 M1 的 GAME，區分渲染與學習帶來的空間差異。

每張圖片的損失如下，之後對 batch 中圖片等權平均：

```
mean_valid_pixels((100*D_raw - 100*D_gt)^2)
+ 0.1 * abs(sum(D_raw)-N) / sqrt(max(N,1))
+ 1.0 * sum(max(-D_raw,0)) / sqrt(max(N,1))
```

計數損失用 raw，選輪與報告用 clamp 後密度，兩者刻意不同；逐輪記錄 raw／clamped 計數、負質量與損失項，避免負值抵銷造成表面改善。所有求和只含有效區域。推論還原原圖沿用雙線性插值及 float64 總量校正，不用真值重標定計數。

## 固定資料及取樣

保留原八類 holdout；其餘 81 類按 ≥300 圖片數降序、同數按類別名稱字母序排名，依序加入第 2、4、6…名，達到至少十張密集圖即停止。此規則由官方標註核算的結果為新增 `roof tiles`、`tomatoes`，不是按模型輸出選類別。

- 擬合集：79 類、3,263 張，其中 32 張 ≥300。
- 留出集：10 類、396 張，其中 11 張 ≥300；完整名單為 bottles、caps、coins、fishes、kidney beans、naan bread、peppers、roof tiles、spring rolls、tomatoes。
- 每輪擬合清單為全部擬合圖一次，加密集圖各三次，共 **3,359 次樣本、420 批**。以實驗種子加零起算 epoch 打亂；種子 43／44 同樣使用自身種子。
- 增強沿用原固定公式，以原擬合清單中的圖像索引計算。同圖同輪的四次出現使用相同增強；這是固定權重重複，不另外引入新的隨機增強規則。
- 官方 val A／B 圖片和類別分折保持原樣。GeCo2 曾在 train 類別訓練，396 張留出只供選輪，並非獨立泛化證據。

## 檢查點與停止規則

訓練前先在同一 396 張、無增強的留出集算 B0 檢測 MAE／RMSE並保存逐圖值。每輪以 clamp 後密度 RMSE 選最佳訓練輪次，同分取較早輪；第 0 輪只作起點參照，不混入訓練檢查點選擇。

第 10 輪結束時，若**當輪**留出 RMSE 嚴格大於 B0 同集 RMSE，立即停止並記錄負結果；不是比較歷史最佳，也不改用 MAE。保留 best／last、逐輪留出預測與凍結雜湊，不自動續訓或跑額外種子。此條件觸發後，本入口不做候選驗證，先交回負結果；未觸發則完成 30 輪，沒有其他平台期早停。預算／OOM／非有限值等中止都不當作完整訓練。

## 執行前檢查

固定既有 32 張 gate，不重新挑圖。以單次特徵前向同時產生 M1 和殘差輸入；原框／objectness／SAM 分數對原始模型逐位元核對，最終框對已保存 B0 逐位元核對。初始計數與 B0 差值最大須 ≤1e-4，密度有限非負、補邊零；以 float64 積分作核對。每輪末 GeCo2 全狀態雜湊不變且無梯度。

新分支多了一個輸入通道及完整 SAM 後處理，因此仍做有界容量驗證：batch 4 四步，沿用原投影公式與 15% 裕量；投影不超過 36,000 MiB 才做 batch 8 四步。**若 batch 8 不符合原停止線，就停止本次方案，不自行降 batch 或改累積步數。** 正式訓練重置模型、種子與 optimizer，容量測試更新不沿用。allocated >40,000 MiB、OOM、非有限值、來源／資產／等價核驗失敗均停止，不自動重試。

## 驗證、候選與預算

完整 30 輪後，先獨立核算選輪、權重及凍結記錄，再以最佳檢查點做 32 圖密度 gate 及全部 1,286 張 val，各自核算。報告原協議的 MAE／RMSE、三組數量分組、GAME(1／2)、逐類別結果、改善／退步／不變數和圖片／類別配對 bootstrap（2,000 次、seed 42）；另報 300–499／500–999／≥1,000 比值。定位 F1 仍是凍結 B0 的框中心，不能算作殘差分支的新定位成果。

主結果為 v2 直接計數。計數候選須同時滿足：MAE ≤1.02×B0、RMSE <B0、≥300 MAE <B0；GAME(2) <原 M1 才可宣稱空間品質改善。只有通過前三項才允許種子 43、44 重訓，並受剩餘總預算約束；seed 42 仍為主結果。v2 額外的 8×8 融合只是可選次要比較，須另行登記實作，本次入口不執行。

每次訓練最多 7 小時，單次驗證最多 90 分鐘；R2-1b 最多 0.5 小時，S 融合紀錄最多 0.5 小時。所有前置、診斷、失敗、驗證和種子工作都納入 M4 30 小時帳本，原已用約 5.01 小時照計。新帳本導入原耗時一次，共用程序鎖、每步結算，單步上限取原上限與總剩餘額度的較小值，保留收尾時間。

M4-ft 的條件保留，但不能用 S 記錄型融合啟動；若未取得 v2 的規定證據、30 輪損失趨勢、真實 FSCD 框及剩餘預算，不執行。test 凍結與人工盲標仍是必要前置。兩份原始草案在 `docs/source_drafts/`；本文件明確化 258 通道、數值尺度、當輪停止判定及有限資源下的行為，所有設定固定於首次診斷之前。
