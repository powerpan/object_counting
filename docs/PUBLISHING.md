# 推送與資料公開規則

每完成一個可核對的開發進展、實驗或負結果，就更新進度文件、檢查差異並推送。提交訊息使用繁體中文，交代具體變更、驗證方式及仍未完成的部分。

例如：「建立 GeCo2 基線環境與驗證集隔離入口；記錄 CUDA 算子測試結果」。不能以「完成訓練」描述只啟動了程序。

推送範圍：方法文件、程式、公開來源與版本、去識別化環境摘要、實驗設定、逐圖數值結果及彙總。資料集圖像、模型權重、完整原始日誌與快取另外保存。

不得推送姓名、個人電郵、學號、帳號資料、SSH 端點、連接埠、密碼、金鑰、Token、帳單或含個人名稱的本機絕對路徑。提交作者使用專案匿名名稱與專案用電郵；推送前檢查 commit 作者和內容。

倉庫歸屬及推送帳號由 GitHub 平台顯示，無法藉匿名 commit 隱藏。公開程式及文件不額外寫入擁有者的個人身分資訊。
