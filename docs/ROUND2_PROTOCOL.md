# 第二輪實驗事前規則：M4、M2-v2、M3-v2

登記日期：2026-10-18。此為經現有程式核對的執行定稿，先提交並推送，再執行任何第二輪 gate、容量試驗或訓練。設定版本：`configs/round2_v1.json`。原始審閱草案保持不變，修訂差異見 `docs/ROUND2_PLAN_REVIEW.md`。

本文件先於第二輪任何結果建立。所有門檻、候選設定與停止條件在開跑前固定；之後的修改一律以「修訂」另記日期與理由，不回寫成事前決定。

## 0. 出發點與共同規則

第一輪已完成：B0（官方 GeCo2）val MAE 9.390、RMSE 33.263、≥300 組 MAE 113.436；M2-v1 退步，M3-v1 MAE 下降但 RMSE 上升、區間跨零；五組皆未通過候選門檻。第一輪的兩個失敗線索直接決定本輪設計：

1. M2-v1 的 228 個增補示例中，53 個框含多個物件（例：`3481.jpg` 一框含 67 點，計數 316 → 29）。
2. M3-v1 的全圖候選超過 800 時，上游略過 SAM 遮罩修正，但各裁片候選少於 800 而會修正；切片因此同時改變了尺度與遮罩分支。另外，裁片門檻以「各片自身最高 objectness × 0.11」計算，片間不一致。

共同規則（沿用第一輪，除非下列另有說明）：

- 官方 FSC 專用權重、上游 commit `67d27e8a93f14226f94d1f2c5c6dab5b5dd7162b` 固定；Hiera 主幹在所有變體中凍結；FP32、TF32 關閉。
- 只用 train 訓練；val 作開發與選擇；**不讀 test 圖像或標註**，直到第 5 節的凍結清單全部完成。
- 推論策略的輸入不含真值；真值只在推論後計分。
- 每組完整 val 1,286 張，逐圖保存，並通過與第一輪相同的獨立核算。
- 每個新入口必須先通過等價 gate：在「關閉新功能」設定下，32 張 gate 圖的原始框、objectness、SAM 分數與 B0 逐位元一致。
- 配對 bootstrap 2,000 次（圖片、類別各一），種子 42；差值一律為「新方法 − B0」。

### 類別兩折交叉驗證（本輪新增）

本輪部分模組有少量候選設定需要選擇。為避免「在同一批 val 上選參又報告」，所有需要選擇的項目採**以類別分折**的兩折交叉驗證：

- 將 val 的 29 個類別依類別名稱字母序排列，奇數位為 A 折（15 類）、偶數位為 B 折（14 類）。完整類別及圖片清單已寫入 `configs/round2_splits_v1.json`，由主設定記錄 SHA-256；A 折 496 張、B 折 790 張，之後不得更改。
- 在 A 折選出最佳設定，在 B 折上報告；反之亦然。合併兩折的「折外（out-of-fold）」預測作為該模組的正式 val 結果。
- 選擇準則固定為：折內 MAE 最低，且折內 RMSE 不高於 B0；若無設定滿足 RMSE 條件，取 RMSE 最低者。
- 平手依另一項指標，再依設定檔的候選順序決定。寬度、候選設定、特徵標準化及融合係數，都只能使用當次擬合折；另一折只作預測。M4 先依密度計數選寬度，再在同一擬合折擬合該寬度的融合 gate。
- 最終 test 所用設定：以全部 val 重做一次相同準則的選擇。
- 分折減少本輪設定選擇的直接洩漏；由於第一輪已分析過整個 val、且本輪有多階段開發，折外結果仍是開發證據，不稱為全新的獨立測試。

### 候選門檻（與第一輪相同）

一組結果進入下一階段的條件：整體 MAE ≤ B0 的 102%、RMSE 低於 B0、≥300 組 MAE 低於 B0，且須對照第 2–4 節列出的對照組判讀。≥300 組只有 39 張、9 類，因此同時報告逐類別結果；任何結論不得只依該組。

## 2. M4：密度分支與區域融合

### 2.1 輸入特徵

以官方三個示例執行凍結的 GeCo2 前向，取 `QueryAdapter.decode` 內的 `adapted`（高解析 dense query map，256 通道，1024 畫布的 1/2 解析度）與 `centerness`（objectness map），兩者在通道維度串接，objectness 保持 `class_embed` 的原始輸出，不當成機率。特徵即時計算，不使用快取，以便資料增強。M4-head 訓練時 GeCo2 全部參數 `requires_grad=False`，並在每個 epoch 末核對凍結參數雜湊不變。

### 2.2 監督目標

- 每個官方點標註產生一個 2D 高斯，σ = 示例平均邊長（模型畫布像素）÷ 4，再換算到輸出解析度（÷2），下限 1 像素。
- 高斯在有效（未補邊）區域內截斷後重新歸一化為 1，與 M1 相同的守恆規則；補邊區域目標為 0。
- 訓練時目標乘以固定比例 100；預測除以 100 後再積分計數。

### 2.3 架構與訓練（兩個候選，事前固定）

| 項目 | M4-head-S | M4-head-L |
|---|---|---|
| 卷積層（3×3，GroupNorm＋GELU） | 257→256→256→256→128→64，再 1×1→1 | 各層通道 ×2（257→512→512→512→256→128） |
| 按本文件設定計算的參數量 | 2,142,401（待實例化核對） | 7,381,377（待實例化核對） |
| 輸出 | Softplus，非負 | 同左 |

共同設定：

- 損失：`L = mean_pixels((100·D̂ − 100·D)²) + 1.0 × |ΣD̂ − N| / max(N, 1)`，N 為該圖真實點數。
- AdamW，學習率 1e-4，weight decay 1e-4，cosine 衰減至 1e-6，前 1 epoch 線性 warm-up；梯度範數裁切 1.0。
- 30 epochs；batch 先試 4；只有依固定記憶體＋批量增量、另加 15% 裕量推估 batch 8 峰值不超過 36,000 MiB，才試 8。每次容量試驗為 4 步，重設種子及參數後才正式訓練；累積步數固定為 1。凍結 GeCo2 特徵逐圖計算，再組成 4／8 張的密度分支批量；不將單圖 QueryAdapter 假稱支援整批推論。
- 增強：水平翻轉 p=0.5；尺度抖動改為上游基準縮放係數再乘 U[0.8, 1.0]，圖像、示例框、點標註同步轉換。原先在上游之前統一放大會被重新縮放抵消；新範圍能實際改變尺度並保留 1024 畫布與 80 px 示例上限。不做隨機裁切（上游的 80 px 示例規則與 1024 補邊會與裁切互相影響）。
- 種子 42。以 seed 42 全 val 選出的單一寬度，另用種子 43、44 各重訓一次，報告同一寬度三種子的平均與範圍。這是以已選寬度為條件的開發敏感度分析，不冒充三次獨立的寬度選擇／折外確認；正式折外結果採 seed 42 各折選出的檢查點。

### 2.4 檢查點與寬度選擇

- **不用官方 val 早停。** 從 train 的 89 類中，依類別名稱字母序每 10 類取第 10 類，共 8 類作為「train-holdout」，其餘 81 類、3,457 張訓練；holdout 為 202 張。固定執行 30 epochs，每 epoch 以 train-holdout 的密度計數 MAE 選最佳檢查點，同分取較早 epoch；不因平台期提前結束。預算或異常中止不算完成 30 epochs。
- 注意：GeCo2 本身訓練過這 8 類，train-holdout 上的特徵偏樂觀；它只用於早停，不作效果證據。
- 兩種寬度以第 0 節的類別兩折交叉驗證在官方 val 上選擇，報告折外結果。

### 2.5 區域融合 gate 與 M4-ft

**融合 gate（R2-2）**：

- 有效區域切為 8×8 格。每格特徵：檢測數、密度積分、平均 objectness、檢測框平均邊長、示例中位邊長、每單位面積檢測數。
- 模型明確定義為 sigmoid 線性混合權重回歸，不是二元分類的 logistic likelihood。格計數 = w·M1 格內密度積分 + (1−w)·M4 格內密度積分；以格的真實點數做最小平方擬合。「框中心數」仍可作輸入特徵，但不能代替會跨格的 M1 高斯質量。
- **只在官方 val 上以類別兩折交叉驗證擬合與報告**（GeCo2 在 train 圖上過度自信，不能用 train 擬合）。
- 最終密度圖 = 各格內 w·M1 + (1−w)·M4 密度，積分必須等於報告計數（容差 1e-6）。

**M4-ft 啟動條件**：只有在 M4-head 折外結果的 MAE 或 ≥300 組 MAE 低於 B0，且第 26 epoch 平均訓練損失相對第 30 epoch 下降超過 5% 時才啟動。這個下降訊號只作啟動條件，不足以證明欠擬合。

- 解凍：GeCo2 的 `class_embed`、`bbox_embed` 及 `adapt_features.up3`（其可訓練卷積為 `adapt_features.up3.layer.1`）；Hiera 及其餘仍凍結。
- 損失：M4 密度損失 + 上游 GeCo2 偵測損失（權重 1.0，取自固定 commit 的訓練程式）。偵測監督另需官方 FSCD 的 `instances_train.json` 真實框；目前點標註不能替代完整偵測框。取得並核驗該資產、固定版 `utils.losses.SetCriterion` 及 `train.py` 主／輔助損失組合通過有界前反向核對後，才允許 ft。若無法忠實重用上游偵測損失，M4-ft 取消並記錄，不自行改寫偵測損失。
- 學習率 1e-5（解凍部分）、1e-4（密度分支），其餘同 2.3。
- 額外檢查：M4-ft 的檢測計數（未融合）不得比 B0 退步超過 2% MAE，否則視為破壞偵測分支。

### 2.6 M4 的報告與門檻

- 報告三種計數：檢測（B0）、密度積分（M4 單獨）、融合（M4＋gate）；另報 GAME(1)／GAME(2)。定位 F1 採檢測框中心與真值點的一對一最大配對，半徑為原圖示例平均邊長的 0.5 倍，報 micro／macro F1。密度與融合不額外抽取峰值，因此不能把原檢測 F1 當成密度分支的新定位成果。
- 融合結果套用第 0 節候選門檻。另需 GAME(2) 低於 M1，才宣稱密度圖空間品質改善。
- 預算：M4-head 每次訓練 ≤ 6 GPU 小時，M4 全部（含種子與 ft）≤ 30 GPU 小時；超過即停止並記錄。

## 3. M3-v2：遮罩分支一致的切片

### 3.1 相對 v1 的變更（只有這三項）

1. **遮罩分支一致**：在 adapter 加入 `refine` 參數（`auto` = 上游行為、`off`、`on`）。裁片沿用全圖第一輪的實際分支：全圖略過修正，所有裁片也略過；全圖有修正，裁片也修正。
2. **全圖一致的門檻**：裁片檢測以「同一張圖所有裁片的最高 objectness × 0.11」為門檻，不再各片自算；跨片 NMS 的 objectness 正規化也用同一全圖值。branch-only 對照仍保留 v1 的各片門檻及正規化。
3. **放大倍率**：兩個事前候選，2×2 與 3×3 網格（實際倍率由各片位置、長寬比及 80 px 示例限制決定，不假設固定 2.5 倍），halo 皆為全圖寬高的 10%；以類別兩折交叉驗證選擇。

觸發規則、核心區歸屬、跨片 NMS（IoU 0.5）、示例特徵取自全圖等其餘設定與 v1 相同。單一放大輸入（1536–2048）不在本輪範圍：上游固定 1024 座標與特徵網格，需另行設計，不是單一參數。

### 3.2 對照組

| 組別 | 目的 |
|---|---|
| `m3-v2` | 上述三項變更 |
| `m3-v2-branch-only` | 只做變更 1（v1 的各片門檻、2×2），分離遮罩分支的效果 |
| `m3-v2-repeat` | 同觸發條件、同推論次數的全圖重跑；必須與 B0 逐位元一致 |
| `b0-refine-on` | 全圖強制遮罩修正（`refine=on`），不切片；檢查修正本身在密集圖是否有益 |
| `b0-refine-off` | 全圖強制略過修正，不切片 |

`b0-refine-on`／`off` 直接回答第一輪留下的問題：遮罩修正在密集圖上是幫助還是傷害。若 `b0-refine-off` 本身已通過候選門檻，即記錄為獨立發現，不併入 M3 的功勞。

### 3.3 必報診斷

觸發圖數、每片候選數（修正前）、核心區歸屬後數量、跨片 NMS 移除數、遮罩分支（auto／off／on）分布，以及第一輪的 `865.jpg`、`3665.jpg` 在 v2 下的結果。這兩張只作機制說明，不作效果證據。

## 4. M2-v2：單一物件示例與一致性回退

### 4.1 相對 v1 的變更（只有這三項）

1. **單一物件過濾**：候選框若包含第一輪**其他**檢測框中心 2 個以上（中心落在框內，不含自身），即剔除。只用模型自身的檢測，不讀真值。
2. **一致性回退**：若第二輪計數與第一輪相差超過 50%（`|c2 − c1| / max(c1, 1) > 0.5`），該圖保留第一輪結果，並記錄回退。
3. **候選設定**：`max_extra_exemplars` ∈ {1, 3}、`min_mean_cosine` ∈ {0.75, 0.85}，共 4 組，以類別兩折交叉驗證選擇。

其餘（objectness ≥ 0.5、尺度比 ≥ 1.5、最小邊 2 px、每個尺度區間最多一個、重用主幹特徵）與 v1 相同。

### 4.2 對照組

| 組別 | 目的 |
|---|---|
| `m2-v2` | 上述三項變更 |
| `m2-v2-repeat` | 同觸發、同數量，但新增的是複製的原始示例；隔離候選內容的影響 |
| `m2-v2-no-fallback` | 只做變更 1 與 3，不回退；僅作診斷，不參與門檻 |

### 4.3 必報診斷

觸發圖數、候選總數、被單一物件過濾剔除的數量、回退圖數；推論後以真值檢查候選框內含點數的分布（與 v1 的 53／228 比較），以及 `3481.jpg` 在 v2 下的結果。

### 4.4 放棄規則

若 `m2-v2` 折外 MAE 差值的圖片配對區間下限大於 0（明確退步），M2 不進入 R2-6 組合，並在報告中列為負結果。

## 5. 組合、凍結與 test 前清單

R2-6 的每個外折，只能用其擬合折決定模組是否通過候選門檻，另一折不得參與模組納入或 gate 擬合；最終 test 版本再用全 val 固定清單。只組合通過候選門檻的模組；組合順序固定為 B0 → M2-v2 → M3-v2 → M4 融合。組合結果同樣以類別兩折交叉驗證報告，並套用第 0 節門檻。

進入 R2-7 前必須全部完成並提交：

- [ ] 最終系統的設定檔、程式提交雜湊、檢查點 SHA-256
- [ ] 以全部 val 重做的最終設定選擇記錄
- [ ] 定位匹配半徑、GAME 網格、密度分組界線（<50／50–299／≥300）
- [ ] 遮擋／雜亂人工標記規則，由未看預測的標記者完成約 200 張 test 圖的標記
- [ ] CARPK 的示例框取法（每圖固定取前三個標註框）
- [ ] 計畫書成功條件原文：相對官方 GeCo2，test RMSE 下降、≥300 組 MAE 下降、整體 MAE 增幅 ≤ 2%

test 只執行一次；結果無論好壞都完整報告，不回頭修改任何設定。

## 6. 資源與停止條件

- 沿用現有 48GB 實例。預算上限：M4 ≤ 30 GPU 小時；M2-v2＋M3-v2（含對照）≤ 10 GPU 小時；組合、test、CARPK ≤ 8 GPU 小時。任何階段超出即停止，先記錄再討論。
- 停止條件沿用第一輪：OOM、非有限值、資料或 B0 計數不一致、等價 gate 失敗；allocated 超過 40,000 MiB 停止後續批次；單組完整 val 上限 90 分鐘。
- 每完成一個可核對階段即更新進度並推送；未完成的工作不標記為完成。

## 7. 本輪不做的事

- 不修改 Hiera 主幹、不重訓 GeCo2 全模型、不加入外部訓練資料。
- 不用真值過濾 M2 候選或觸發 M3。
- 不以第一輪或本輪的個別案例調整門檻。
- 單一放大輸入（1536–2048）、LoRA、合成密集資料留待日後，需另立規則。

## 8. 實作定義與執行記錄

- 3×3 卷積不含 bias，GroupNorm 固定 32 groups；最後 1×1 卷積有 bias。最後權重初始化為 0，bias 為 softplus 的反函數，使初始「乘 100 的密度」為每有效像素 0.01；避免預設 Softplus 在 512² 網格上產生極大初始總量。
- 以 `Q` 表示分支直接輸出的非負「乘 100 密度」，實際密度為 `Q/100`，不重複乘除。損失為有效像素平均 `(Q−100D)^2` 加上正規化計數誤差，再按圖片平均；補邊輸出與目標皆為零。高斯截斷範圍固定為 3σ，每點在有效區域重新歸一化；浮點邊界沿用第一輪規則，縮放取整後邊緣點歸入最後有效網格。
- 翻轉時同步轉換圖像、示例及點；驗證／holdout 不增強。原圖恢復密度採雙線性插值，再以 float64 校正總質量；不得因縮放改變計數。
- 融合特徵在擬合折以均值／標準差標準化，常數欄標準差設為 1；零初始化係數，L-BFGS-B 最多 1,000 iterations，L2=0.001（不含截距），平方誤差對每圖的 64 格等權。其餘容差固定於設定檔；不另做正則化搜尋。
- `refine=auto` 直接沿用原實作；`off` 保留修正前的框與 objectness。`on` 超過 800 候選時分成最多 800 的區塊呼叫同一上游修正程式，保持其內部每 50 框處理順序，立即釋放遮罩；不修改上游檔案。每張記錄實際分支與候選數。
- M2-repeat／no-fallback 使用主方法在擬合折選出的同一設定；no-fallback 不另外挑最佳設定。M3-repeat 額外次數與該折選定網格的裁片數一致。
- 正式訓練保留 `last` 與 `best` 檢查點、optimizer／排程／RNG 狀態及每 epoch 凍結參數 SHA-256。只有明確的中斷恢復可續跑同一工作；OOM、非有限值、核驗或預算失敗不得自動重啟。模型權重不放進公開 Git。
- 預算以占用 GPU 的工作程序牆鐘時間計算，含模型載入、容量試驗和驗證；M4 的 30 GPU 小時是所有種子、寬度、ft 的合計上限，並非每組各 30 小時。容量試驗／等價 gate 也先登記後執行。
- 每次首次執行保存方案提交 SHA、程式提交 SHA、設定／資料／權重 SHA-256 及伺服器 UTC 開始時間。方案先推送，之後的修正另建修訂記錄；不以改寫本機 Git 時間作為獨立可信時間證明。
- R2-7 的盲標約 200 張 test 圖需要未看預測的人工標記者；自動生成標籤或本代理自稱人工審查均不能代替。此依賴未滿足時停止在 test 之前，M4／M2／M3 的 train／val 工作可照計畫完成。
