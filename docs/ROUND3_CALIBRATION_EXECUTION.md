# M4-v3 開跑前實作核對

2026-10-18。本文件補齊第三輪規則 `ab4f53a` 第 4、9 節的 CPU 實作。程式、測試與本文件先提交推送；只有 TTA 三組完整 val、兩折選擇及獨立核算都完成並回收後，才首次擬合校正。這個入口只評估以 B0 為基礎的校正，組合另行接續。

我們從已核算的 B0 檢測框重建 M1、原圖整數 8×8 格質量及官方點數，無須再載入 GeCo2、原圖或 GPU。四個特徵沿用事前定義：log(1＋格質量)、log(示例中位邊長)、log(格內框平均邊長)、格質量除以畫布格面積。框邊長為原圖寬高的算術平均，無框格用示例中位邊長；面積乘以保存 B0 scale 的平方。框邊長非正、非有限或輸入雜湊錯誤直接停止，不臨時加 epsilon。

只有正質量格進入 Poisson 目標與擬合折的特徵標準化；零質量格不因點標註而增生預測。常數欄以觀測值完全相同判定，std 固定為 1。區域版的五個參數、L2＝1、不懲罰截距、未裁切 link、零初始化及 L-BFGS-B 的各項設定均照原登記。global 的解析截距只用相同正質量格；零目標以標記保存邊界解，預測倍率為 0.5，JSON 不寫入無限值。預測在 log 空間限制到 log(0.5)／log(2) 後取 exp，與原定裁切倍率相同，避免預測階段的溢位；擬合目標不作此裁切。

每個外折都先在擬合類別內按字母序奇偶分成兩個內折，得到區域版與 global 的內部交叉預測。只用這些預測決定版本與三項納入門檻，RMSE 相同選 global；再以全部外層擬合圖片重擬合，預測外折。保存所有內折清單、係數、逐圖值和選擇記錄。全 val 最終版本另以相同內部分折決定，再用全 val 擬合；它與折外成績分開，不產生 test 數值。

報告四份折外結果：原始區域版、原始 global、依內折選出的版本，以及未通過內折納入門檻時退回未校正輸出的版本。前兩份不因版本選擇而省略。每份都報整體／數量組／類別指標、GAME 與原 2,000 次圖片及類別配對區間；另披露兩折區域係數的符號是否一致。檢測框不改動，不宣稱定位召回改善。

獨立核算另寫逐格特徵及點數的重建，檢查每次擬合使用的圖片、正質量支援、標準化、Poisson 目標、解析 global、內折選擇與外折預測。區域係數以同一固定優化器重擬合作可重現性檢查，這部分不稱為另一種獨立優化演算法；由係數還原倍率、完整密度圖、積分、GAME 與計數指標則另行計算。數值核對沿用 `rtol=1e-12, atol=1e-8`；獨立浮點特徵重建後的優化器係數比較採 `rtol=1e-7, atol=1e-7`，不據此改動任何模型或門檻。

新入口為 `scripts/run_round3_calibration.py`，結果目錄為 `results/round3-calibration-v1`。執行前核對已推送的新增來源憑據、原 93 份來源、B0 audit、TTA 完成 manifest、val 分割及標註 SHA；已有結果目錄即拒絕重跑。全程隱藏 CUDA，使用 NumPy／SciPy，不載入神經模型。本機 CPU 分析上限 600 秒，未收斂、非有限或核算失敗保存診斷後停止。GPU 帳本不增加虛構費用，也不改寫 TTA 的完成帳本；另記本機 CPU 牆鐘時間。

測試以人工構造資料覆蓋幾何／格面積、正質量格篩選、Poisson 梯度與未裁切 link、常數特徵、global 解析解及邊界、密度守恆、未收斂拒絕、類別分折與平手規則。另直接改變外折真值，確認該折的擬合係數和內部決策不受影響。這些測試不使用真實 val 分數選擇設定。
