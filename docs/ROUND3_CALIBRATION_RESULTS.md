# M4-v3 本機 CPU 校正結果

2026-10-18。程式與執行口徑先以 `5abe00d` 推送；TTA 完整證據發布後，首次在真實 val 擬合。14:34:52 UTC（香港 22:34:52）完成，獨立核算通過，CPU 牆鐘 **12.67 秒**，沒有新 GPU 推論或神經訓練。

**本次校正不納入後續組合。** 區域版與 global 對照的 RMSE 雖下降，MAE 卻分別增加約 **6.32%／4.99%**，超過事前允許的 2%。兩個外折內部都選 global，但都未通過納入門檻；按規則執行後的輸出完整退回 B0。區域版也沒有比單一倍率取得更好的整體結果。

## 我們擬合了甚麼

使用 FSC-147 官方 val **1,286 圖、29 類、82,042 個目標**；每圖中位數 27、平均 63.80、範圍 7–2,092。密集組定義為真值至少 300，有 39 圖、9 類、23,182 個目標。真值仍為官方點標註。

模型讀取已保存的 B0 框及 M1 密度，將原圖分成 8×8 格，以四個固定特徵及一個截距擬合 Poisson 校正；倍率限制在 0.5–2。只擬合正密度格，零密度格維持零。global 使用同一正質量支援和目標，只擬合單一倍率。損失、L2、特徵標準化、優化器及停止條件均沿用[事前執行口徑](ROUND3_CALIBRATION_EXECUTION.md)，沒有按結果調參。

外層 A／B 按類別分開，分別為 496／790 圖。在每個外層擬合折內，再按類名字母序奇偶分兩個內折。只用內部交叉預測選 regional 或 global、決定是否納入；然後重擬合整個外層擬合折，預測外折。所有內折圖片、係數、預測和決策均保存。全 val 的將來選擇另記，不使用外折標籤替該折作決定。

## 四份折外結果

MAE 是每圖平均絕對計數誤差，RMSE 對大誤差更敏感，單位均為「個／圖」；GAME(2) 是每圖 4×4 區域絕對計數誤差之和的跨圖平均。以下越低越好。

| 結果角色 | MAE ↓ | RMSE ↓ | ≥300 組 MAE ↓ | GAME(2) ↓ | 三項門檻 |
|---|---:|---:|---:|---:|---|
| B0／M1 | 9.38958 | 33.26304 | 113.43590 | 15.56047 | 參照 |
| 原始區域校正 | 9.98296 | 32.54166 | 113.21345 | 15.82121 | 未通過 |
| 原始 global | 9.85843 | 32.11227 | 111.06538 | 15.84297 | 未通過 |
| 內折選版本後 | 9.85843 | 32.11227 | 111.06538 | 15.84297 | 未通過；兩折選 global |
| **內折決定是否納入後** | **9.38958** | **33.26304** | **113.43590** | **15.56047** | **兩折都不納入，退回 B0** |

原始區域版 RMSE 下降 2.17%，global 下降 3.46%，但兩者 MAE 都超過上限 **9.57737**。少量組（<50）的 MAE 從 B0 的 2.29392 升至區域版 2.92658／global 2.87045；中量組也退步。降低少數大失誤的代價，是更多一般圖片誤差增加。GAME(2) 亦高於 M1，沒有取得空間密度品質改善。

這裡的「否」來自擬合類別內的交叉預測，不是看到外折結果後改判。全部 val 重擬合的 global 倍率為 1.06469，但不取得最終候選資格，不會因為係數已產生就套用到 test。

區域版係數依序對應截距、標準化後的 log(1＋格質量)、log(示例邊長)、log(格內框邊長)、格檢測密度。兩折使用各自擬合統計標準化，數值大小不能直接當相同原始單位比較。

## 不確定性、核算與接續

差值為方法減 B0；圖片與類別配對 bootstrap 均為 2,000 次、種子 42。

| 方法／指標 | 點估計差 | 圖片配對 95% 區間 | 類別配對 95% 區間 |
|---|---:|---:|---:|
| regional MAE | +0.59338 | [+0.28043, +0.92727] | [−0.02732, +1.24503] |
| regional RMSE | −0.72138 | [−2.29344, +1.37673] | [−2.37556, +1.68089] |
| global MAE | +0.46885 | [+0.00554, +0.93208] | [−0.29552, +1.21945] |
| global RMSE | −1.15078 | [−3.54609, +1.52714] | [−3.76861, +1.75406] |

RMSE 改善區間仍跨零，圖片配對的 MAE 區間支持退步；類別配對較寬。這批 val 已反覆用於開發，不能以其取代獨立 test。按納入規則退回 B0 後，差值與區間均為零，這是拒絕不合格校正的結果，不是校正成功。

執行前核對 99 份來源、原 93 份 TTA 來源、完整 TTA manifest、基準與官方標註 SHA。核算入口另行重建格特徵、點數、標準化、目標、內折決策、倍率和四份完整密度圖；計數、GAME、分組指標與配對區間均通過。完整密度積分與報告計數的最大差為 **2.27×10⁻¹³**。係數重擬合沿用同一固定優化器，用來檢查可重現性，不能稱為另一種獨立優化演算法。

此階段本機 GPU 使用為零，未改動已結算的第三輪 GPU 實驗帳本；雲端實例依指示保持開機，這不代表平台停止計費。尚未執行組合、M2-v2、test 或 CARPK。下一步按固定順序處理 M3／TTA／遮罩的折內納入與組合；本次不合格的校正不帶入，也不再自動重試。
