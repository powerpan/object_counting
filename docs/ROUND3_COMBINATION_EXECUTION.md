# 第三輪組合的執行口徑

2026-10-18。依 `ROUND3_PROTOCOL.md` 第 5、9 節接續。TTA 與 M4-v3 結果已公開；本文件及新增入口在第一次組合選擇前提交推送。組合設定、門檻與順序不變，不以完整 val 表格代替擬合折的納入判斷。

先執行本機 CPU 規劃入口 `scripts/run_round3_combination_plan.py`。對外折 A，只用 B 的圖片決定 M3 網格、TTA 版本、遮罩策略及各模組是否納入；對外折 B 反之。三個模組均沿用已登記的 MAE／RMSE 選擇規則，再逐一檢查 MAE 不超過同折 B0 的 102%、RMSE 較低、密集 MAE 較低。全 val 的將來決策另存，不冒充外折成績。

校正是否納入，直接讀取已獨立核算的 M4-v3 擬合類別內交叉預測決策，核對其擬合圖片完全一致。不能看到新組合後替未通過的校正開第二次機會。本次已完成的兩個外折及全 val 校正決策都是不納入；仍保存此來源與判斷。若任何決策要求校正重擬合，規劃只列出需求，須另補齊執行入口，不把它假定為完成。

圖像路由固定如下：M3 已納入且原 B0／示例條件觸發切片時，使用相應網格的已核算 M3 結果；其餘圖使用已納入的 TTA，否則 B0 全圖。遮罩策略只作用於這一全圖路徑，包括 TTA 的每個全圖視圖；不回寫 M3 的原始觸發或裁片跟隨分支規則。未使用 TTA 時，強制遮罩可直接引用已完成的 `b0-refine-on/off`。使用 TTA 且同時納入強制遮罩時，需要對應的 `T2/T4-refine-on/off` 輸出，不能把未強制遮罩的 TTA 冒充它。

入口保存逐折、逐圖路由和缺少的推論版本清單，缺少版本取聯集，不重跑已具備的結果。將來全 val 路由也只作來源需求清單，不在這個階段計分。所有判斷使用已登記折內資料；路由本身不讀真值。若需補跑強制遮罩 TTA，先完成該入口、測試和來源登記，才於原實例執行，計入 R3-4 的 3,600 秒上限。不得借用前階段剩餘額度。

規劃前核對既有來源、TTA 完成 manifest、M3 完整 manifest、校正 audit／模型／執行狀態及各候選逐圖 SHA。獨立核算另算折內指標、候選順序、納入條件、路由及缺少的來源。`plan_execution_v1.json` 最後只到 `awaiting_combination_implementation`，不代表完成組合、凍結或 test；已有目錄拒絕重新建立，失敗留存診斷。

測試覆蓋外折真值隔離、路由不讀真值、失敗模組退回 B0、遮罩與 TTA 同時／分別啟用、M3 優先順序、類別交疊、觸發不一致、錯誤校正折，以及核算拒絕篡改納入／路由／缺少來源。只使用合成資料，不以真實組合分數修正規則。

新增 10 項測試，連同既有第三輪共 49 項本機 CPU 測試通過。這只核驗規劃程式，還沒有組合的實測成績。

規劃在本機 CPU 執行，另記牆鐘，不增加 GPU 實驗用量，也不改寫 TTA 的完成帳本。實例依指示保持開機；這不代表雲端停止計費。M2-v2 仍為最後可選開發階段；正式凍結及獨立人工盲標完成前，禁止執行 test、CARPK 或替代人工標註。
