# 第三輪開跑前核對

2026-10-18。這份核對與執行版協議先於第三輪運算提交。原始草案保留，沒有回寫早期實驗的來源或結果。

我們接受第三輪方向：停止 train 監督的密度分支與 M4-ft，先做 M3-v2，再測 TTA 和 val 類別交叉擬合的小模型。正式 test 成功標準收緊至 RMSE 至少改善 2%、圖片配對區間完全低於零、密集 MAE 至少改善 5%、整體 MAE 退步不超過 2%。尚未產生 test 數值。

需要更正的是證據強度。S 在訓練密集圖本身也少計，v2 沒有跑正式 val；現有資料不能證明「兩者共同因 train 類別沒有錯誤可學而失敗」。分布差異可以作研究動機，但不是已排除損失設計、特徵或擬合問題後的因果結論。S 約 389 是本次觀測最大值。v2 的可核對結論是第十輪留出 RMSE 上升並觸發規則，不能直接寫成未見類別或所有密集場景失敗。

執行版補清三項原稿歧義：分項預算合計 10.5 小時；五種 M3 報告角色實際需七份完整輸出；區域與 global 及組合的選擇只能在擬合折完成。若用合併外折成績再挑版本、又把同一成績當成所選模型的無偏驗證，仍會洩漏。校正選擇因此使用擬合類別內的固定兩折，與既有「折內選擇、折外報告」原則一致。其他數值口徑與停止條件已寫入協議第 9 節及設定檔。
