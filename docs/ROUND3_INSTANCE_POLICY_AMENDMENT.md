# 第三輪實例運行政策修訂

2026-10-18，M3-v2 完整核算後、TTA 開跑前記錄。

專案負責人明確要求「不要關機」。從此以最新指示為準，既有 AutoDL 實例在各階段之間保持運行，取消自動關機安排；除非之後再有明確指示，不因流程完成或追蹤提示而關機。既有磁碟和實例保留，不另租或更換 GPU。

當時已開啟關機確認框，確認操作被介面工具攔截；隨後核對平台仍顯示運行中，且確認框已不存在。沒有把一次嘗試記為成功關機。

本項只修改資源運行安排。原事前文件與來源雜湊保留，M3 證據不回寫；各階段計算上限、先提交再運行、共用鎖、停止條件、擬合折選擇與 test 人工條件均不變。實例持續運行所產生的平台費用，與程式帳本的計算耗時分開記錄。
