# M2-v2 開跑前實作核對

本次執行第三輪原方案的可選 M2-v2，沒有新訓練或新參數搜尋。TTA、CPU 校正及不含 M2 的組合均已完成並發布；既有實例依最新指示保持開機。本文件、程式與測試須先提交推送，才開始下列真實 val 運算。

## 固定的四組設定

| 順序 | 額外示例上限 | cosine 下限 |
|---|---:|---:|
| `m2-v2-e1-c075` | 1 | 0.75 |
| `m2-v2-e1-c085` | 1 | 0.85 |
| `m2-v2-e3-c075` | 3 | 0.75 |
| `m2-v2-e3-c085` | 3 | 0.85 |

選擇沿用原類別兩折：只看擬合折，在 RMSE 不高於同折 B0 的設定中取最低 MAE；若全部未符合 RMSE 條件，取最低 RMSE。平手先比另一項指標，再按表列順序。這個選擇規則與三項候選納入門檻分開，不能將「選中」解讀為「納入」。repeat 和 no-fallback 均跟隨主方法的同一選擇，不各自挑選最好結果。全 val 的將來設定另記，不代替折外分數。

## 與既有程式對齊

第一輪使用已核算的 GeCo2／SAM2、三個官方示例、原縮放與後處理。每張第一輪框須逐位元重現 B0；主幹特徵只計算一次，第二輪只重新提取示例 ROI 特徵和執行解碼。SAM 沿用上游 auto 行為，沒有額外強制遮罩策略。

原 v1 的相對 objectness ≥0.5、尺度比 ≥1.5、模型座標最小邊長 2 px、每尺度區間最多一個、按 objectness×cosine 穩定排序均保持不變。cosine 沿用三層 ROI 相似度平均，再取三個原示例中的最大值。新增規則只有原協議的三項：

1. 候選框包含至少兩個**其他**第一輪檢測中心時剔除。用模型像素座標，四邊均包含邊界，自身中心扣除一次；剔除發生在尺度區間競爭之前，避免被剔除框佔用名額。
2. 第二輪與第一輪的數量相差嚴格大於 50% 才回退。剛好 50% 不回退；分母為 `max(c1,1)`。回退保留第一輪框、數量和密度。
3. 僅使用上表四組候選。

推論 API 不接收點標註。候選框內真值點數在推論返回後才計算，只作診斷；不據此過濾、重排或修改任何門檻。第一輪的約 53／228 多物件候選是比較背景，不是本次選參依據。

## 對照與核算

四組主方法及四組 repeat 各自執行 GPU 推論。repeat 使用相同的候選過濾、觸發與額外示例數量，但按原順序循環複製原示例；同樣執行回退規則。複製提示可能改變結果，因此不要求 repeat 等於 B0；必須等於 B0 的是每張第一輪及前置等價 gate。

no-fallback 直接使用主方法已保存的第二輪框與密度：回退圖另外保存原始第二輪密度，其他圖片引用同一陣列。這正是取消回退後的輸出，無須再做四次相同的 GPU 推論。獨立核算從保存的框重建密度、計數、逐格質量、GAME 和定位；raw 對照標示 `diagnostic_only`，不參與候選或組合門檻。報表分開記錄「回退規則會觸發」與「實際已回退」，避免 raw 對照誤報回退。

每組記錄第一輪檢測候選總數、通過原幾何／相似度門檻的數量、被單物件規則剔除的數量、最終示例數、觸發和回退圖數。另報候選框內真值點數分布及 `3481.jpg`，不把個例當整體成效。

核算會重新檢查來源、資料與 B0 雜湊，以另一份幾何選擇實作核對排除自身、邊界、排序、尺度區間與回退，再重建空間輸出。折外核算另算選擇和指標；主方法 MAE 差值的圖片配對區間下限若大於零，依原規則記錄明確退步，排除後續含 M2 的組合。區間跨零亦不代表已證明改善。

## 執行與資源

`run_round3_m2_workflow.py` 持有三個共用鎖，要求 TTA 完整 manifest／已結算帳本及已發布組合的核算憑據。新增 receipt 同時覆蓋先前本機 CPU 程式和本次新增程式，舊 TTA 的 93 個來源保持不變。CPU 測試與合成測試不使用真實 val 來挑設定。

順序為 CPU 測試 → 32 圖原始輸出等價 gate → 八組各 32 圖 smoke 及核算 → 八組各 1,286 圖 full 及核算 → 主方法類別兩折選擇、兩個對照隨行 → 獨立折外核算。任何 smoke 失敗均阻止全部 full；smoke 成績不改設定。

新帳本在 `results/round3-m2-v1`，只導入已完成 TTA 帳本一次；TTA 和更早帳本不再寫入。前置計入 R3-0，M2 推論及核算共同計入 R3-5 的 7,200 秒；單組 full 最多 5,400 秒，allocated 上限 40,000 MiB。不可借其他階段額度，active 耗時尚未結算時不能另加一次。OOM、非有限值、來源／資料／等價／核算失敗或超限即停止相依工作，保留診斷，不自動重跑或覆寫。

本機新增 13 項合成測試，第三輪合計 69 項 CPU 測試通過。包含排除自身、邊界中心、剔除先於尺度競爭、原 v1 門檻不變、50% 嚴格邊界、空輸出與非有限值、主幹重用、repeat 提示內容及 raw 對照的回退統計。這不代替伺服器等價 gate 和 smoke 核驗。

控制器到 `awaiting_publication` 只代表 M2 完成。若需要加入 M2 的組合，須另完成實作核對與事前提交，在原 R3-4 額度內執行；不能將先前不含 M2 的組合改名當作新結果。最終凍結、獨立人工盲標及 test／CARPK 仍未完成。控制器沒有關機、釋放實例或新租資源的動作。
