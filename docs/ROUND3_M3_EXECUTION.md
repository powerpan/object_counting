# M3-v2 執行入口與核算

事前規則已於 `ab4f53a` 推送。以下入口只執行 R3-0 和 R3-1，不自動進入 TTA、校正、訓練或 test。

`scripts/run_round3_m3_workflow.py` 同時持有原 M4、M2/M3 和本輪鎖；要求原 v2 已安全停止、舊帳本沒有未結算工作、沒有其他 GPU 程序。新狀態為 `results/round3-v1/m3_workflow_v1.json`，預算為同目錄的 `budget_ledger_v1.json`。既有輸出一律拒絕重跑，失敗時間仍入帳。

執行順序為遠端 CPU 測試、32 圖原始輸出等價 gate、七組各 32 圖 smoke、七組各 1,286 張完整 val，再作類別折外選擇及獨立核算。每份推論完成後即以 CPU 從官方點數、保存框和密度陣列重建計數、GAME、定位與逐格資料；全部核算通過才繼續。新原始輸出使用已驗證的 Round2Adapter，舊 69 份來源不修改。

裁片原始結果暫存在 CPU，等所有裁片的最大 objectness 確定後，再用原 GPU 後處理次序套用共同門檻；每次只保留一片主幹特徵。密度圖以壓縮陣列留遠端，公開結果只包含數值、框、逐格資料及 SHA-256。強制 SAM on 仍依既定 800 框分塊；沒有放寬 40,000 MiB 停止線。

12 項本機 CPU 測試已通過，覆蓋舊 2×2 幾何相容、2×2／3×3 邊界唯一歸屬、共同門檻與 padding／NMS 次序、空／非有限輸出、重複推論的原始值檢查、強制 SAM 分塊、外折資料不得改變該折設定，以及失敗計費／禁止重複啟動。這些測試不能代替 GPU 等價 gate 或實際方法成績。

本輪程式另建立 `provenance/round3_m3_receipt_v1.json`，保留方案提交、程式提交及所有依賴的逐檔雜湊；原五份 receipt 與 v2 receipt 也必須通過。每個子程序有硬逾時，終止時結算已用時間。R3-0 上限半小時、R3-1 上限三小時，階段不能互借。控制器最後只到 `awaiting_publication_and_shutdown`，此時回收、公開與停機仍需完成。

雲端開機只在程式已提交推送後進行。階段結束或失敗時透過平台停止同一實例並保留磁碟；不以停止 Python 進程假稱平台已停止計費。
