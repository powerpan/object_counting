# 第三輪事前規則：M3-v2、測試時增強（TTA）、M4-v3 驗證集校正

登記日期：2026-10-18（執行版；提交後以提交雜湊為準）。設定版本：`configs/round3_v1.json`。前置文件：`ROUND2_PROTOCOL.md`、`ROUND2_L_CANCEL_AMENDMENT.md`、`M4_V2_PROTOCOL.md`。

本文件須在任何第三輪 GPU 或 CPU 實驗開跑**之前**提交。所有候選設定、門檻與停止條件在此固定；之後的修改另立修訂，不回寫。

## 0. 出發點

- **基準不變**：B0（官方 GeCo2）val MAE 9.390、RMSE 33.263、≥300 組 MAE 113.436。
- **M4 以 train 監督的神經分支結案為負結果，M4-ft 取消。** S 在正式 val 的 MAE／RMSE 為 16.62／83.30；最大預測約 389 是觀測值，不是架構硬上限。原擬合集 ≥500 的 15 張圖，S 預測／真值中位數為 0.3543，已有訓練圖擬合不足的線索。v2 第 10 輪因內部留出 RMSE 比 B0 高 3.42% 而按規則停止，尚無 v2 正式 val。兩者未被證明有同一失敗原因；預訓練類別與未見類別的誤差分布差異是後續方法的動機與待驗假說。檢測計數接近真值也不代表定位或召回率接近完美。
- **因此本輪只做兩類方法**：(1) 不需訓練的推論策略（M3-v2、TTA）；(2) 只在 val 上、以類別兩折交叉驗證擬合的極小型校正（M4-v3），讓模型在未見類別上的真實錯誤成為唯一的學習訊號。
- **M2-v2** 維持 `ROUND2_PROTOCOL.md` 第 4 節的登記內容，優先序降為最後，時間不足即不執行。

共同規則沿用第二輪第 0 節：官方權重與 Hiera 凍結、FP32、TF32 關閉、不讀 test、推論不用真值、等價 gate、完整 val 1,286 張、獨立核算、配對 bootstrap 2,000 次（種子 42）、類別兩折分割沿用 `configs/round2_splits_v1.json`（A 折 15 類 496 張、B 折 14 類 790 張），以及「折內選擇、折外報告」的選擇準則。

## 3. R3-2：測試時增強（TTA）

### 3.1 做法

對同一張圖做數次凍結 GeCo2 推論，計數取**平均**：

- **T2**：原圖、水平翻轉，共 2 次。
- **T4**：{原圖、水平翻轉} × {上游縮放係數 × 1.0、× 0.8}，共 4 次。不使用大於 1.0 的倍率，因為上游已把長邊縮至 1024 畫布並套用 80 px 示例上限。

示例框隨翻轉與縮放同步轉換。每次推論的 M1 密度圖先還原到原圖座標（翻轉回來、縮放回來，總量守恆），再取平均；平均後的密度積分等於報告計數（容差 1e-6）。定位指標使用原圖那一次的檢測框，並在報告中註明。

T2 與 T4 以類別兩折交叉驗證選擇，準則同第 0 節。

### 3.2 對照組

| 組別 | 目的 |
|---|---|
| `tta-repeat` | 原圖推論 4 次取平均；必須與 B0 逐位元一致，證明 TTA 的差異來自翻轉與縮放，而不是重複計算 |

### 3.3 必報診斷

各次推論之間的計數差異（每圖標準差），以及差異與絕對誤差的相關；耗時與顯存。

## 4. R3-3：M4-v3 驗證集區域校正

### 4.1 模型

- **單位**：每張圖有效區域的 8×8 格，沿用第二輪融合的網格定義。
- **輸入**（每格）：d = 該格 M1 檢測質量；以及四個特徵：`log(1+d)`、`log(示例中位邊長)`、`log(格內檢測框平均邊長)`（無檢測時以示例中位邊長代替）、格內檢測密度（d ÷ 格面積，以畫布像素計）。
- **輸出**：校正係數 `g = clip(exp(β₀ + β·x), 0.5, 2.0)`；格計數 `c = g × d`。d = 0 的格維持 0。
- **擬合**：Poisson 回歸（log 連結，offset = log(d)，只用 d > 0 的格），目標為該格官方點數；特徵以擬合折的平均與標準差標準化；L2 懲罰 λ = 1.0（不懲罰截距）。共 5 個參數。
- **最終計數** = Σ c；**最終密度圖** = 每格的 M1 密度乘以該格 g，積分等於計數。

### 4.2 交叉驗證與報告

- A 折擬合、B 折預測，B 折擬合、A 折預測；合併折外預測為正式 val 結果。
- 最終 test 用的係數：以全部 val 擬合一次。
- 報告兩折各自的係數，檢查方向是否一致；不一致時在報告中註明，不改設定。

### 4.3 對照組

| 組別 | 目的 |
|---|---|
| `m4-v3-global` | 只有截距（單一全域係數 g₀，同樣折外擬合），檢查區域特徵是否比「全部乘一個常數」更有用 |

區域版與 global 都獨立報告折外結果。供組合採用的版本必須只在擬合折內比較；區域版的 RMSE 未嚴格低於 global 時選 global。不得看外折成績後更換該折版本，細則見第 9 節。

## 5. R3-4：組合與凍結

只組合通過第二輪候選門檻（整體 MAE ≤ B0 的 102%、RMSE 低於 B0、≥300 組 MAE 低於 B0）的模組，順序固定：

1. 若 M3-v2 通過：觸發切片的圖用 M3-v2；其餘圖用 TTA（若 TTA 通過）或 B0。遮罩策略若通過，套用於全圖推論。
2. 若 M4-v3（或 global）通過：在上一步的輸出上**重新**以相同類別兩折擬合校正係數，不沿用 B0 上擬合的係數。

組合結果同樣以折外方式報告並套用門檻。全部不通過時，以 B0 作為最終系統，test 只用來報告 B0 與已完成模組的負結果。

## 6. test 前凍結清單（新增收緊後的成功條件）

除 `ROUND2_PROTOCOL.md` 第 5 節原清單外，test 的成功條件改為計畫書的收緊版本。這項修改在任何 test 數值產生之前登記：

相對官方 GeCo2，在 test 上同時滿足：

- (a) RMSE 至少下降 2%，且圖片配對 bootstrap 95% 區間的 RMSE 差值完全低於 0；
- (b) ≥300 組 MAE 至少下降 5%；
- (c) 整體 MAE 增幅不超過 2%。

未達到的改善一律不稱為成功；小幅或區間跨零的改善記為「不確定」，明確退步仍如實記為負結果。

## 7. 升級路線（不預先批准）

若 R3-4 沒有任何組合通過門檻，下一步候選是「微調 GeCo2 解碼器並加入放大切片的訓練增強」（估計 15–20 GPU 小時，M4 預算尚餘約 22.7 小時）。這條路線不包含在本文件內：必須先另立事前方案，並取得專案負責人明確同意後才執行。

## 9. 開跑前的實作定義與歧義處理

本節與前文一同提交。原始草案逐字保留於 `docs/source_drafts/ROUND3_PROTOCOL_20261018.md`；差異說明見 `ROUND3_IMPLEMENTATION_REVIEW.md`。若草案、計畫書簡述與本節有差異，以本執行版及設定檔為準，不在看到第三輪結果後另作解釋。

### 執行與預算

- 表內上限加總為 **10.5 GPU 小時**（含 0.5 小時前置），不是精確的 10 小時。各階段不借用其他階段餘額，也不動用舊 M4 剩餘預算。CPU 本機開發／分析不占 GPU 預算；遠端階段從程序啟動到結束的牆鐘時間（含載入、測試、核算、失敗）均計入該階段，另記實例開／關機時間供帳單核對。每個完整 val 工作仍不超過 90 分鐘，allocated 不超過 40,000 MiB。
- R3-0 先提供 M3 所需測試與 32 圖等價 gate；TTA／M4-v3 的實作可在各階段之前補齊。每個新增入口仍須先測試、提交、推送再運行，不能把尚無程式的階段標成完成。
- 先完成 M3-v2，再停機回收／核算與準備 TTA。階段結束或失敗後停止實例，保留磁碟；不刪除／釋放實例，不另租資源。關機可能令原 GPU 被他人占用；無餘量時保存狀態並等待，不自行換卡。
- M2-v2 為最後的可選開發階段。R3-4 的凍結先記為「候選凍結」；若執行 M2，正式 test 凍結必須在其結果與同順序組合完成後重新提交，且仍在原各階段上限內。未完成時不納入最終系統。test、CARPK 仍受人工盲標及凍結清單約束，本輪預算不是跳過這些條件的授權。
- OOM、非有限值、來源／資產／等價失敗、超時或顯存超線即停止相依工作，保存已發生耗時與診斷；不自動換參數、不無限重試。原 M4、L 和舊控制器不得恢復。

### M3：五種報告角色、七個實際輸出

順序固定為 `m3-v2-g2`、`m3-v2-g3`、`m3-v2-branch-only`（固定 2×2）、`m3-v2-repeat-g2`、`m3-v2-repeat-g3`、`b0-refine-on`、`b0-refine-off`。每組先做固定 32 圖 smoke，只檢查正確性和資源，不依分數修改設定；其後各自完整 val。

- 主方法兩個網格按原類別兩折準則選擇；repeat 使用同一折選出的網格，觸發圖在原第一輪之外額外重跑 4／9 次完整全圖，逐次框及原始輸出須完全一致。非觸發圖仍為一次 B0。
- 裁片核心邊界為 `floor(i*W/g)`、`floor(j*H/g)`，左上包含、右下不含；halo 為全圖寬／高的 10% 向上取整，核心歸屬及 IoU=0.5 的框 NMS 與 v1 相同。不是「中心距離 NMS」。
- 主方法門檻為**所有裁片**的原始 objectness 最大值乘 0.11，不是未切片全圖的最大值。原始 objectness 也作片內／片間 NMS 分數；branch-only 保留各片最大值。空裁片直接忽略，無候選時回傳空結果，不把零作分母。
- 全圖第一輪必須逐位元重現保存 B0。實際 SAM 分支由修正前候選數是否大於 800 決定；所有裁片跟隨該分支。強制 on 超過 800 時沿用已登記的 800 框分塊與上游每 50 框運算，沒有改權重。
- 遮罩 on／off 均獨立報告；作組合時在擬合折按第 0 節的 MAE／RMSE 規則選擇（同分 off 優先），並在該折檢查三項門檻。所有外折選擇清單一併保存。遮罩策略不能算成切片的改善。
- B0、M3 與遮罩策略均保存框、分數、8×8 M1 質量、GAME 與定位配對。密度、分組、類別和配對區間沿用原定義；原圖及密度陣列留遠端，公開逐格資料與雜湊。

### TTA 與校正的固定數值口徑

- TTA 的 1.0／0.8 作用於**最後**上游縮放係數；padding 維持右／下。密度先裁 padding、逆翻轉與恢復原圖，float64 校正質量後平均。repeat 檢查每一次的原始框／分數與 B0 位元一致；平均採第一張加各張相對第一張的差值平均，避免重複相同陣列的求和尾差冒充增強差異。
- M4-v3 使用原圖整數 8×8 格。示例、檢測框邊長用 `(寬+高)/2` 的原圖像素；格面積換算為 `原圖格面積 * B0上游scale**2`。組合後仍用同一 B0 座標尺度。空格邊長以示例中位邊長代替；質量為 0 的格不擬合且預測保持 0，故不能補出完全沒有檢測質量的區域。
- Poisson 目標固定為有效格的 `mean(mu - y*eta) + 1.0*sum(beta**2)`，`eta=log(d)+截距+標準化特徵@beta`、`mu=exp(eta)`，不懲罰截距；擬合時不裁切 link，預測才把係數裁至 [0.5,2]。float64、零初始化、L-BFGS-B、maxiter=1000、ftol=1e-12、gtol=1e-8；常數特徵 std=1。非有限或未收斂停止，不改正則或重啟搜尋。global 使用同一目標的截距解析解，再裁切；零目標時下限 0.5。
- 區域／global 的版本選擇及納入組合不能使用外折標籤。在每個外折的擬合類別內，依字母序奇偶再作固定兩折內部交叉預測，以其 RMSE 選較佳版本（相同選 global），並檢查三項納入門檻；選好後在整個外層擬合折重擬合，只預測外折。最終版本在全部 val 以同一兩折內部規則決定，再以全部 val 重擬合。區域與 global 的兩份原始外折結果仍完整公開。
- 組合中的 M3／TTA／遮罩設定和是否納入，皆只用該外折的擬合圖片決定，最後在組合輸出上重新擬合校正。外折不能反過來決定模組。全 val 的最終清單和折外開發成績分開陳述。這批 val 已多次用於方法開發，交叉驗證不能把它變成獨立 test。
