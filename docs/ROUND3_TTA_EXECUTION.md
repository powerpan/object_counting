## 推論口徑

順序固定為 T2、T4、tta-repeat。T2 使用原圖／水平翻轉各一次；T4 再加入這兩者的 0.8 倍版本；repeat 則是原圖共四次。倍率作用於原圖經上游 1024 畫布和 80 像素示例上限處理後的最終 scale，不重新用 1024 將 0.8 倍抵消。原圖 1.0 倍直接使用既有 `prepare`，其餘視圖同步變換 RGB 與三個示例框，padding 仍在右／下。各視圖使用原始自動 SAM 分支；本階段不套入遮罩 on／off 的選擇。

M1 是由檢測框建立的單位質量高斯密度。本次將逆變換施加於其生成框，再在原圖網格建立 M1：先以同 B0 的 float32 算術將框除回有效 scale；翻轉視圖再按連續框座標 `x'=W-x` 還原；每個框在原圖上的高斯核以 float64 歸一化，然後平均各視圖密度。這是 M1 的幾何投影實作，避免另外改變 B0 的核定義。每張視圖積分等於該次檢測數，平均圖積分等於平均計數，容差 1e-6。保存各視圖正規化框、還原框、scale、有效尺寸與數量，供獨立核算。

唯一座標尾差處理是：反向翻轉若將零寬邊界框的中心放在恰好 W，允許在八個 float64 ULP 範圍內將中心平移到有效半開區間；超出範圍即失敗，不丟棄檢測或放寬條件。此邊界情況在合成測試固定，不根據 val 調整。

repeat 每次原始框、objectness、SAM 分數均須逐位元一致；最終框和 M1 陣列也相同。其平均以首張加差值均值實作，保留 B0 的原始位元。原圖第一遍的檢測框在每張圖都須與已保存 B0 相同。32 圖 gate 另直接比較官方 model 與 adapter 的原始輸出。

定位及供後續校正使用的檢測框邊長特徵，均固定取原圖 1.0 倍那一次；密度質量則取平均密度。多視圖計數標準差使用母體公式 `ddof=0`；診斷報告其與平均計數絕對誤差的 Pearson 相關。標準差為零時相關未定義，記 null，不捏造為零。這些診斷不參與選擇。

## 核算與選擇

每組先完成相同 32 圖 smoke，只用於正確性和資源核驗，再做全部 1,286 張 val。核算從各視圖框重建原圖 M1、平均密度、8×8 質量、GAME、原圖定位和數量，核對陣列及檔案雜湊。空檢測視圖保留零圖，也進入平均分母。

T2／T4 使用原 A／B 類別折，只有擬合折能選設定。選擇、外折逐圖值、統計與三項候選門檻再由另一套選擇／指標核算邏輯檢查。整批 val 的將來固定選擇另存，不能當折外成績；是否組合仍需擬合折內判斷。前置或單組分數均不改設定。
