# M4-v2 事前規則：以 M1 為起點的殘差密度分支

登記日期：2026-10-18（草案；提交後以提交雜湊為準）。設定版本：`configs/m4_v2.json`。前置文件：`ROUND2_PROTOCOL.md`、`ROUND2_L_CANCEL_AMENDMENT.md`。

本文件須在 R2-1b（訓練集密集圖檢查）結果公開**之前**提交；R2-1b 的結果不得用來修改下列任何設定。

## 1. 相對 M4-S 的變更（只有這四項）

| 項目 | M4-S | M4-v2 |
|---|---|---|
| 輸出形式 | 從零預測密度 | 在 M1 密度圖上預測殘差 |
| 計數損失 | `|ΣD̂ − N| / N` | `0.1 × |ΣD̂ − N| / √max(N, 1)` |
| 訓練取樣 | 每圖每輪一次 | ≥300 個物件的圖每輪出現 4 次 |
| 早停資料與準則 | 8 類 holdout，MAE | 擴充 holdout（含足夠密集圖），RMSE |

其餘設定沿用 M4-S：GeCo2 全部凍結、FP32、TF32 關閉；架構寬度 257→256→256→256→128→64（GroupNorm＋GELU），再 1×1；AdamW 1e-4、weight decay 1e-4、1 輪 warm-up 後 cosine 至 1e-6、梯度裁切 1.0；30 輪、batch 8、種子 42；增強為水平翻轉 p=0.5 與 U[0.8, 1.0] 尺度抖動；目標高斯 σ = 示例平均邊長（1024 畫布）÷ 8，下限 1 像素，截斷後重新歸一化。

## 2. 殘差設計

- **M1 輸入**：以凍結 GeCo2 的最終檢測框，在 512 輸出網格的有效區域上渲染 M1 密度圖（規則與 M1 相同：每框一個總量為 1 的高斯，σ 與框尺寸成比例，截斷後重新歸一化）。M1 圖作為第 258 個輸入通道，與 `adapted`（256）、`centerness`（1）串接。
- **輸出**：`D_raw = M1 + r`，r 為網路輸出（無 Softplus，可正可負）。最後一層權重與偏差**初始化為 0**，因此訓練前 `D_raw = M1`，計數等於 B0 檢測數。
- **報告用密度**：`D = max(D_raw, 0)`，計數 = ΣD；D 也是最終密度圖。
- **負值懲罰**：`1.0 × Σ max(−D_raw, 0) / √max(N, 1)`，防止以負密度抵銷。

## 3. 損失

```
L = mean_valid_pixels((100·D_raw − 100·D_gt)²)
  + 0.1 × |ΣD_raw − N| / √max(N, 1)
  + 1.0 × Σ max(−D_raw, 0) / √max(N, 1)
```

N 為官方點數。三項權重事前固定，訓練中不調整。√N 正規化使大量少計的代價隨密度上升，同時避免極密集圖完全主導梯度。

## 4. 取樣與早停

**密集圖加權取樣**：每輪的訓練清單 = 擬合集全部圖片各一次，加上點數 ≥300 的圖片各額外 3 次（共 4 次），在清單內以種子 `42 + epoch` 打亂。報告每輪實際樣本數及密集圖數量。

**擴充 holdout**：

1. 保留原 8 類 holdout。
2. 將其餘 81 類依「≥300 個物件的圖片數」由多到少排序（同數以類別名稱字母序），依序加入第 2、4、6…名的類別，直到 holdout 中 ≥300 的圖片至少 10 張為止。
3. 被移入 holdout 的類別不參與擬合。開跑前公開最終 holdout 類別名單、圖片數與密集圖數。

**早停準則**：每輪以擴充 holdout 的 **RMSE** 選檢查點（RMSE 對嚴重少計敏感）。同時記錄 B0 在同一 holdout 的 MAE／RMSE 作為起點參照。GeCo2 訓練過這些類別，holdout 數值只用於選檢查點，不作效果證據。

## 5. 前置檢查（不通過即停止）

1. **起點等價**：訓練前（第 0 輪），32 張 gate 圖上 M4-v2 的計數與 B0 檢測數的最大絕對差 ≤ 1e-4，密度非負且有限。
2. **凍結核對**：每輪末 GeCo2 凍結參數雜湊不變。
3. **安全停止**：若第 10 輪時 holdout RMSE 仍高於 B0 在同一 holdout 的 RMSE，停止訓練並記錄為負結果。因為起點即為 B0，這代表訓練在傷害結果。

## 6. 評估與門檻

- 完整 val 1,286 張，與 B0、M4-S 同一批圖片與示例。報告整體及 <50／50–299／≥300 組的 MAE、RMSE，GAME(1)／GAME(2)，定位 F1（匹配半徑 = 示例平均邊長 × 0.5），以及 S ÷ 真值式的分組比值表（同第 2 節修訂文件格式）。
- 另報「改善／退步／不變」圖數、逐類別 MAE，以及圖片與類別配對 bootstrap 區間（2,000 次、種子 42）。
- **候選門檻**（與第二輪相同）：整體 MAE ≤ B0 的 102%、RMSE 低於 B0、≥300 組 MAE 低於 B0；並須 GAME(2) 低於 M1，才宣稱空間品質改善。
- M4-v2 本身就是一種學到的檢測／密度融合，因此以 M4-v2 直接計數作為主要結果；R2-2 的 8×8 區域融合 gate 可在 M4-v2 上加跑一次，只作次要比較。
- 若通過門檻，以種子 43、44 各重訓一次，報告三種子的平均與範圍；正式結果仍用種子 42。

## 7. 預算與停止

- 單次訓練 ≤ 7 GPU 小時（密集圖重複取樣使每輪變長）；含 R2-1b 與額外種子，M4 合計仍受 30 GPU 小時上限約束，L 已用時間照計。
- 停止條件沿用第二輪：OOM、非有限值、凍結雜湊改變、起點等價失敗、allocated 超過 40,000 MiB。
- 本文件之後的任何修改另立修訂，不回寫。

## 8. 本輪不做

- 不再訓練從零預測的 L 型或其他寬度。
- 不以 R2-1b 或 val 結果調整損失權重、取樣倍數或 holdout 名單。
- 不解凍 GeCo2（M4-ft 維持原啟動條件，且只能建立在 M4-v2 之上）。
