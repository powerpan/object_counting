凍結、最終評估與交付工作說明

日期：2026-10-22。對象：遠端合作者。目的：方法開發至此結束；依下列順序完成最終評估與交付物。本文件提交後即為事前登記，之後的修改另立修訂，不回寫。

## 0. 總原則

- **方法不再修改。** 不新增模組、不調參、不重跑已完成的 val 實驗。
- **test 只跑一次。** 跑完不論結果好壞都完整報告，不回頭改任何設定，也不重跑。
- **test 與 CARPK 的結果不得用來選擇或調整任何東西。**
- **成功條件不放寬**（見第 4 節）。
- 每一步先提交再執行，沿用現有的核算、帳本與 SHA 紀錄方式。

## 1. 雲端實例：立即處理

1. 確認沒有 GPU 程序與控制器在執行。
2. 把只存在伺服器上的成果備份到持久位置（密度陣列、所有檢查點、原始日誌），並以已記錄的 SHA-256 核對。資料集與官方權重可重新下載，不必備份。
3. **關機（power off），不要釋放或刪除實例。** 之後的 test、CARPK 與 demo 錄製需要同一環境。請先確認 AutoDL 對長期關機實例的保留規則，必要時在期限前開機一次。
4. 只在第 5、6、8 節需要 GPU 時開機，做完即關機。專案負責人確認最終報告後，才可釋放實例。

本節取代 `ROUND3_INSTANCE_POLICY_AMENDMENT.md` 的「保持開機」安排。

## 2. 凍結最終系統（第一個提交）

提交 `configs/final_v1.json` 與 `docs/FINAL_FREEZE.md`，內容至少包括：

- **最終系統**：
  - 觸發條件與第三輪相同：原始三個示例在 B0 輸入中的面積平方根中位數 ≤ 32 像素，或 B0 預測數 ≥ 200。
  - 觸發的圖：M3-v2 3×3 切片，遮罩分支與全圖一致，門檻取同一張圖所有裁片的最高 objectness × 0.11。
  - 其餘的圖：T2（原圖＋水平翻轉，計數取平均，M1 密度逆投影後平均）。
  - 不強制遮罩、不校正、不含 M2。
- **基準**：B0（官方 GeCo2，原圖一次推論），與最終系統在同一次執行中評估。
- 程式提交雜湊、設定雜湊、官方 GeCo2／SAM2 權重 SHA-256、資料集清單 SHA-256。
- **物件尺寸分組界線**：相對示例尺寸 `r = sqrt(三個示例框平均面積 ÷ 圖像面積)`。以 val 全部 1,286 張的三分位數作為小／中／大的界線，**在 test 前計算並寫入設定**。
- **其他評估定義**沿用既有：密度分組 <50／50–299／≥300；定位匹配半徑 = 示例平均邊長 × 0.5；GAME(1)／GAME(2)；配對 bootstrap 2,000 次、種子 42，圖片與類別各一。

## 3. 遮擋／雜亂人工盲標（由專案負責人團隊完成）

這一步需要**沒看過任何預測或計數的人**來標，不能由程式或看過結果的人完成。合作者負責準備材料：

1. **抽樣**：test 中全部真值 ≥300 的圖，加上其餘圖片依密度分組分層隨機抽樣，合計約 200 張；種子 20261022，名單提交後不得更改。
2. **標記表**：CSV，每行一張圖，只提供圖檔名與圖片本身。**不提供**計數、真值點、預測或類別以外的任何資訊。
3. **標記定義**（寫在表頭）：
   - 遮擋：`none`（目標物幾乎都完整可見）／`partial`（明顯部分目標互相或被其他物體遮住）／`heavy`（多數目標被遮住一部分以上）。
   - 雜亂：`low`（背景單純、少有相似干擾物）／`high`（背景複雜或有大量外觀相近的非目標物）。
4. **一致性**：另請第二位標記者獨立重標其中 40 張，報告 Cohen's kappa。
5. 完成的標記表由專案負責人交回，**在 test 執行前提交並記錄 SHA-256**。

## 4. 成功條件（test，已登記，不得放寬）

相對官方 GeCo2，在 FSC-147 test 上同時滿足：

- (a) RMSE 至少下降 2%，且圖片配對 bootstrap 95% 區間的 RMSE 差值完全低於 0；
- (b) ≥300 組 MAE 至少下降 5%；
- (c) 整體 MAE 增幅不超過 2%。

未全部滿足時，報告為「點估計改善但不確定」或「未改善」，不稱為成功。

## 5. 單次 test 執行

前置條件：第 2、3 節的提交全部完成。

- **資料**：FSC-147 官方 test 1,190 張、29 類，官方前三個示例框，真值為點標註個數。
- **同一次執行**輸出 B0 與最終系統的逐圖計數、框、M1 密度及耗時與顯存。
- **報告**：
  - 整體 MAE／RMSE；密度分組、尺寸分組、逐類別的 MAE／RMSE；
  - GAME(1)／GAME(2)、定位 precision／recall／F1；
  - 盲標子集：遮擋與雜亂各分組的 MAE／RMSE（標註每組圖片數）；
  - 第 4 節三項條件逐項判定，附圖片與類別配對區間；
  - 觸發切片的圖數與比例。
- 獨立核算後才公開。結果無論好壞都完整報告。

## 6. CARPK 跨資料集檢查

- **資料**：CARPK 官方 test 集（以下載的官方檔案為準，記錄 SHA-256 與張數）。
- **示例框**：每張圖固定取標註檔中的前三個框；真值為標註框總數。
- **執行**：B0 與最終系統各跑一次，設定與 test 相同，**不在 CARPK 上調整任何東西**。
- **報告**：MAE／RMSE、觸發切片比例、配對 bootstrap 區間。
- 預算：第 5、6 節合計 ≤ 2 GPU 小時。
